# 2026-09-15 Figma 디자인 원본 에셋

사용자가 Figma에서 직접 export한 `/Users/baek/Desktop/newsvg`의 SVG 70개와
3배율 PNG 4개를 바이트 변경 없이 보관했다. 조사 채널은 `wvkqunn6`이다.

- `icons/`: 원래 파일명과 `2828/`, `3636/` 하위 경로를 보존한 SVG.
- `images/`: `Empty_01x3.png`, `Empty_02x3.png`, `Empty_03x3.png`, `favicon_viva_50x3.png`.
- `manifest.json`: 파일별 원본 상대 경로, SHA-256, 용량, SVG viewBox와 마스크 수, PNG 해상도.

이 폴더는 기획 확정 및 후속 구현을 위한 원본 보관본이다. 아직 pubspec의 런타임
에셋 목록에 등록하지 않았으며 기존 앱의 아이콘과 화면은 교체하지 않았다.
기존 `assets/icons/`에 보관된 공통 SVG는 그대로 유지한다.

## 후속 적용 시 확인할 사항

- 원본을 수정하지 않는다. Flutter 마스크 호환성 등을 위한 변환이 필요하면
  별도 런타임 에셋을 만들고 원본과의 대응 관계를 남긴다.
- 색상, 마스크, 원형 배경을 보존했다. 다색 SVG를 일괄 tint하거나 포함된 배경을
  위젯에서 중복해서 그리지 않는다. Flutter 렌더링 검증은 후속 구현에서 수행한다.
- `2828/`, `3636/`는 각각 28×28, 36×36 원본이다. 루트의 일부 파일과 중복되지만
  사용자가 전달한 원본 구성을 보존하기 위해 삭제하지 않았다.
- `speed_1_2x`처럼 같은 이름으로 내보낸 변형은 파일명만으로 상태를 결정하지 않고
  실제 도형을 대조한다. 파일명의 숫자 접미사는 export 중 이름 충돌을 구분하는 값이다.
- `check`, `restart_alt`, `power_settings_new`, `workspaces`는 도형에 맞춰 잘린
  viewBox이므로 Figma의 상위 아이콘 영역과 구분해 배치한다.
- `Toast_V.svg`에는 되감기 도형과 배경·문구가 함께 포함돼 있다.
- Empty PNG 3종은 1035×681이며 3배율 표시 크기는 345×227이다.
- favicon PNG는 168×168이며 3배율 표시 크기는 56×56이다. 80×80 카드 버전의
  3배율(240×240) 원본으로 간주하지 않는다.
- `x3`라는 파일명만으로 Flutter의 해상도별 에셋 선택이 적용되지는 않는다.
  후속 구현에서 `3.0x/` 에셋 구성 또는 명시적 scale과 표시 크기를 설정한다.
