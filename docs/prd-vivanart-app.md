- 후속 PRD 섹션에서는 **홈 탭이 `크레캠+사육장` 화면 그 자체**로 확정되었다(§4 참조). 다이어그램과 PRD가 어긋나는 지점이므로 PRD가 우선.

## 2. [개요]

- 게코를 위한 스마트 사육장과, 소형 캠과 연동해서 사용하는 앱. 주요기능은 사육장의 온습도 조절 장치 원격 조정, 펫캠 확인.
- **전제**
  한개의 사육장에는 한개의 캠과 한마리의 도마뱀을 사육한다

## 3. [탭별 주요 기능]

- **크레캠+사육장**: 카메라 실시간 확인, 사육장 IoT 기능 원격 조절
- **통계**: 온습도 그래프, 크레 활동 통계 및 분석
- **마이크레**: 사용자가 크레 정보
- **커뮤니티**: 사육정보 공유
- **기타 기능**
  - 푸시: 주기적인 사육장 청소 알림, 온도 경고 알림

## 4. [기능 요약]

### 가. 크레캠+사육장

> \*캠 기능끼리 / 사육장 기능끼리 탭으로 묶어서
> 캠-사육장 기능 스위치 가능하게 디자인 할 예정
> 즉, 이 페이지 안에 탭이 생긴다!

**메인 기능**

1. 실시간 영상
   1. 영상 송출, 현재 시각 표시
2. 사육장 제어
   1. 현재 사육장의 온도, 습도 표시
   2. 팬 on/off
   3. 히터 on/off
   4. led on/off, 밝기 조절
   5. 분무 – 1회 터치하면 1회 분사

**서브 기능**

1. 영상 하이라이트
   1. 타임라인 형식으로 시간대별 하이라이트 영상 모음
   2. 행동 분류칩으로 이동, 휴식, 식사 등이 분류
      1. 칩을 누르면 영상 sort
      2. 영상이 없는 칩은 비활성화
2. 타이머, 예약 기능 **(논의 필요)**
   1. 적정 온도, 습도 목표 설정
   2. 루틴 설정
      1. 자동 분무
      2. 팬, 히터, led on부터 off까지 시간 지정
      3. 프리셋 제공
   3. 작동 기록 (실제로 작동했는지 안내하기위한 확인, 안심용)
      1. 실행 예정
      2. 실행 결과

**간단 하루 통계 (하루: 어제 오후 7시 ~ 오늘 오전 7시)**

1. 캠
   1. 행동별 횟수
   2. 이동 시간
2. 사육장
   1. 사육장 온습도 실시간 그래프
   2. 최고온도, 최저온도 (실시간 갱신) – **굳이 필요없나?**
   3. 기능 on/off 표시

### 나. 통계

1. 온습도 그래프
   1. 하루의 최고, 최저, 평균 - 라인 그래프 (xy축 표시한 기본 형태)
   2. 주간의 최고 최저 평균 - 표 형식 (애플 날씨 참고)
2. 크레 활동 통계 및 분석
   1. 정량
      1. 활동, 수면, 물/밥 횟수, 탈피
   2. 정성, 추가분석 **(가능한지 기술 체크 필요)**
      1. 이상 행동
      2. 활동량 증감 (전주 대비)
      3. 좋아하는 백업, 장난감

### 다. 마이크레

1. 프로필
   1. 사진, 이름, 성별, 종, 체중, 입양일 (사용자가 수기)
2. 활동 기록, 메모
   1. 급여, 탈피, 채중, 건강, 자유메모 (사용자 수기, **근데 일부는 자동화 가능한가?**)

> \*이런 간단한 기능만 구현할거면 통계로 통합해도 될듯
> 달력+다이어리 처럼 한눈에 보여주는 형태로 간다면 따로 빼는게 맞고
> **우선 후순위**, 가나먼저 구체화

### 라. 커뮤니티

1. 공지사항
2. QnA
3. 자유 게시판
4. 사육 위키
   1. 백색목록 검색
   2. 종정보: 사육 정보 제공
   3. 모프 계산기

### 미결 질문 (원문 그대로)

> \*맨 처음에 크레, 사육장, 캠을 연결하는 스텝은 더 고민 필요
> +사육장이나 캠 없이 크레 일기장으로 쓰는 사람을 고려할 필요가 있나? 없겠죠?

# 5. [PRD] 기능 및 화면 명세서

## 홈 탭 (`/home`)

### 1. 개요 및 화면 정책

#### 1.1 기본 접근 및 렌더링 정책

- **화면 목적**: 실시간 펫캠 감상, 사육장 모니터링, 퀵 제어, 타이머 현황 확인 및 당일 타임라인 확인
- **기기 연동 모드에 따른 홈 탭 UI 자동 전환**:
  - **통합 세트 (사육장 + 캠)**: Top Fixed Live 비디오 뷰어 + 2구분 서브탭 (`[사육장 제어]` | `[타임라인]`) 제공
  - **사육장 단품 모드**: 비디오 뷰어 대신 개체 프로필 대표 카드 노출 + `[사육장 제어]` 서브탭 고정 노출 (`[타임라인]` 서브탭 비활성화)
  - **캠 단품 모드**: Top Fixed Live 비디오 뷰어 노출 + `[타임라인]` 서브탭 고정 노출 (`[사육장 제어]` 서브탭 비활성화)

#### 1.2 시간 정책

- **당일 기준**: `07:00 ~ 익일 07:00` (야행성 활동 주기 반영)
- **최근 24시간 실시간 차트 범위**: 전날 19:00부터 현재 시점까지의 데이터 자동 갱신 노출

> ⚠️ §4 "간단 하루 통계"의 하루 정의는 "어제 오후 7시 ~ 오늘 오전 7시"로 여기와 다르게 적혀 있다. 원문 불일치이며 해석하지 않고 그대로 둔다.

#### 3.2 Top Fixed Area: Live Cam Viewport (비디오 영역)

> *사육장 단품 사용자는 본 영역이 **개체 대표 프로필 카드**로 대체됨.

- **비디오 스트리밍**: WebRTC / RTSP 16:9 실시간 비디오 노출
- **스와이프 UX**: 비디오 영역 좌/우 스와이프 시 다음 등록된 사육장 세트로 전환 (하단 `● ○ ○` 페이지 인디케이터 바인딩)
- **상태 표기 (Status Badge)**:
  - 연결 정상: `LIVE (Red Dot)` 뱃지 노출
  - 네트워크 해제: `OFFLINE (Gray)` 뱃지 노출
- **오버레이 Controls**: 현재 시각 오버레이, 전체 화면 전환 버튼, 캡처 버튼, 수동 녹화 버튼
- **오프라인 안내 화면 (Placeholder)**:
  - 스트림 끊김 발생 시 비디오 중앙에 경고 레이어 노출 ( `⚠️ 사육장 카메라 연결이 끊겼습니다. [재연결]` )
- **사육장 단품 모드 구성 (대체 위젯 카드)**:
  - 사용자 직접 등록 도마뱀 대표 사진, D-Day 정보 (`젤리와 함께한 지 D+152일`), 최근 상태 요약 (마지막 급여일, 체중), 사육장 상태 뱃지 (`온습도 정상 🟢`) 노출

#### 3.3 Sub-Tabs Bar (서브탭 영역)

- **컴포넌트**: `[🎛 사육장 제어]` | `[🎞 타임라인]` 2구분 세그먼트 탭
- **동작**: 서브탭 전환 시 상단 Live 비디오 스트림은 **끊김 없이 고정 유지**
- **단품 분기**:
  - 사육장 단품 ➡ `[🎛 사육장 제어]` 탭 기본 활성화 (타임라인 비활성화)
  - 캠 단품 ➡ `[🎞 타임라인]` 탭 기본 활성화 (사육장 제어 비활성화)
