## 3. 앱 동작 방식 — 서버/펌웨어 쪽이 알아두면 좋은 것

1. **구간 예약은 앱의 생성 헬퍼일 뿐, 서버에는 낱개 2건이다.** 앱은 쌍 메타데이터를 저장하지 않는다(웹 콘솔과의 발산 방지). 대신:
   - off 생성 실패 시 on을 **삭제 롤백**한다 (on만 남으면 히터 과열 위험).
   - **weekly + 자정 넘김**(예: 월 22:00 켜기 / 06:00 끄기)이면 off쪽 `days_of_week`를 **하루 민다**(월→화). 안 밀면 off가 같은 요일 새벽에 걸려 그 주의 on보다 먼저 발화한다. → 웹 콘솔에서 예약 목록을 보면 on/off 요일이 하루 어긋난 쌍이 보일 수 있는데, 의도된 것이다.
2. **가드는 켜기(on) 예약에만 건다.** 끄기 예약에 가드가 걸리면 조건 성립 시 off가 스킵돼 기기가 켜진 채 남는다(히터=과열). 앱 UI는 끄기 예약에 가드 편집을 막아 뒀다. **서버 측에서도 `*_off` action + guard 조합을 400으로 거부해 주면** 웹 콘솔 등 다른 클라이언트 경로까지 안전해진다 (§4-3 요청).
3. **팬 타이머 진행 상태는 앱이 `commands` 이력에서 계산한다** (`issued_at + duration_ms`, 최신 유효 fan 명령 기준). 타이머 표시 중에는 30초마다 재조회해 타 진입점 취소·TTL 만료(pending→expired)를 반영한다.
4. **guard 해제는 `PATCH /schedules/{id}` body `{"guard": null}`로 보낸다.** 가드를 안 건드린 수정은 guard 키를 아예 생략한다(서버 값 유지 기대). → §4-2 확인 요청.
5. LCD는 REST 응답의 `lcd_bitmap`/`lcd_clear` command를 앱이 해석만 하고 직접 INSERT하지 않는다.

## 4. 백엔드 확인/요청 사항

| # | 항목 | 내용 | 중요도 |
|---|---|---|---|
| 1 | **보드 타입 구분 필드** | LED 밝기(§1.4)는 MOSFET 보드만 실동작인데 앱이 보드 타입을 알 방법이 없다. `devices`에 `board_type`(또는 capability 플래그) 컬럼/필드를 노출해 달라. 그때까지 밝기 슬라이더는 미노출 | 중 |
| 2 | **guard 해제 계약 확인** | `PATCH {"guard": null}`이 가드 삭제로 처리되는지, 아니면 400인지 확인 요청. 400이면 대체 방법(`{"guard": {"enabled": false}}` 등) 회신 바람 | 중 |
| 3 | **(제안) `*_off` + guard 서버 거부** | §3-2의 안전 불변식을 서버에서도 강제: `action`이 `*_off`인 예약에 guard가 실리면 400. 앱은 이미 막았지만 웹 콘솔 경로가 남는다 | 중 (히터 안전) |
| 4 | **펌웨어 플래시 일정** | 물분무·팬타이머·LED밝기·LCD 실동작에 플래시 필요(§5). 일정 공유 바람 — 앱 쪽 실기기 검증(팬 타이머 자동 OFF, LCD 렌더, guard 스킵 이력)이 이걸 기다린다 | 상 |
| 5 | **401 정책 참고 공유** | 앱은 terra-api 401 → 전역 로그아웃이다. access token 만료(1h) 직후 자동 갱신 착지 전 요청이 401을 맞으면 불필요한 강제 로그아웃이 될 수 있다. 서버가 만료 토큰과 무효 토큰을 구분해 줄 수 있으면(예: 401 body code) 앱이 refresh-후-재시도로 개선 가능. 급하지 않음 | 하 |
| 6 | **기존 대기 항목 리마인드** | 정지형 가드(가동 중 정지 — 히터 목표온도 도달 시 OFF, 펌웨어 담당)·히터 타이머(pulse). 일정 나오면 공유 바람 | 중 |

## 5. 플래시 후 함께 검증하고 싶은 것 (실기기)

1. 팬 타이머: `fan_on`+duration 발행 → duration 뒤 펌웨어 자동 OFF + `fan_off`로 중도 취소.
2. 분무 `mist` 1/2/3초 실분사.
3. 예약 guard 스킵: 습도 조건 성립 시 `commands`에 `status='skipped', source='guard', reason=...` 기록 확인.
4. LCD: 한글 텍스트 렌더(서버 한글 폰트 설치 여부 포함)·재부팅 유지·`/lcd/clear` 복귀.
5. weekly 자정 넘김 구간: 월 22:00 on → 화 06:00 off가 실제 그 순서로 발화하는지.
