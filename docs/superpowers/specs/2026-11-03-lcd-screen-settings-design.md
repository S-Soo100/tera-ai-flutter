## 1. 목표 / 범위

사육장 모듈 LCD를 앱에서 ① 끄고 켜고 ② 밤 시간대에 자동으로 끄고 ③ 내 개체 사진을 화면 보호기로 띄운다.

**범위 안:** 홈 진입 줄 교체, 모듈 화면 설정 화면, 화면 꺼짐 시간 화면, 화면 보호 사진 설정 화면(사진 고르기·업로드·교체·삭제, 보호기 켜기, 노출 시간), 명령 결과 처리, 구 펌웨어 안내.
**범위 밖:** 사진만 모드(`mode:"image"`), 오프라인 아이콘 끄기(`show_offline_icon:false`), 웹 콘솔, 펌웨어 업데이트(OTA) 유도 화면 — §7 결정에 따라 조정.

## 2. 사용자 체험 시뮬레이션

1. 홈 '기기 설정'에 **모듈 화면 설정 ›** 줄이 있고 오른쪽에 지금 LCD 문구(`viva-iot-…` 또는 바꾼 문구)가 보인다. (기존 '모듈 화면 표시 문구' 줄을 대체)
2. 누르면 **모듈 화면 설정** 화면. 세 묶음:
   - `화면 전원 · 켜짐` [스위치]
   - `화면 표시 문구  <현재 문구> ›` / `화면 보호 사진 설정  꺼짐|켜짐 ›`
   - `화면 꺼짐 예약` [스위치] / `꺼짐 시간  20:00~8:00 ›` + 각주 "설정한 시간 동안 화면을 끄고, 이후 자동으로 다시 켜집니다"
3. **전원 스위치를 끄면** 스위치가 바로 꺼짐 쪽으로 넘어가고 반짝임(shimmer)으로 "기기 확인 중"을 보인다. 1~2초 뒤 기기가 확인하면 반짝임이 멈추고 제목이 `화면 전원 · 꺼짐`. LCD가 꺼진다. 실패하면 원래대로 돌아가고 이유를 띄운다.
   - D1 확정(서버 규칙): 끄면 **다시 켤 때까지 꺼져 있다**(꺼짐 예약이 끝나도 안 켜짐). 꺼짐 예약 시간 안에는 전원이 켜짐이어도 화면이 꺼져 있고, 전원 줄 아래에 "지금은 꺼짐 예약 시간이라 오전 8:00에 켜져요"를 보인다. Figma 규칙(수동 조작이 다음 경계까지만 우선)은 서버·펌웨어 회신 뒤 바꾼다.
4. **꺼짐 예약 스위치를 켜면** 마지막에 고른 시간(처음이면 오후 8시~오전 8시)으로 예약을 보낸다. 같은 방식으로 확인. 끄면 예약 해제.
5. **꺼짐 시간 ›** → 화면 꺼짐 시간 화면. 시작/종료 각각 오전·오후 + 시(1~12) + 분을 위아래 화살표로 맞추고 **완료**. 예약이 켜져 있으면 바로 기기로 보내고 돌아온다(확인 대기는 설정 화면 줄에서 반짝임). 예약이 꺼져 있으면 시간만 기억해 두고 돌아온다. 시작과 종료가 같으면 완료가 막힌다.
6. **화면 보호 사진 설정 ›** → 사진이 없으면 회색 5:4 칸 "사진 추가". 누르면 사진첩 → **5:4 자르기 화면**(D5, §3-6) → 업로드. 칸에 **서버가 만든 미리보기**(기기 화면과 같은 색·자르기)가 뜨고 "기기로 보내는 중" 표시. 기기가 받으면 표시가 사라진다(보통 1~3초, 느린 Wi-Fi 10초).
7. 사진이 있으면 오른쪽 아래 연필 버튼 → `사진 교체 / 사진 삭제` 메뉴.
8. 아래 목록: `보호기 · 켜짐|꺼짐` [스위치], `사진 노출 시간  [−] 1분 [+]`, `온습도 표시 시간  [−] 10초 [+]`, 각주 "모듈 화면에 사진과 기존 온습도 표시가 번갈아 나타납니다". 끝값에서 −/+는 흐려진다.
9. 스위치·시간을 바꾸면 **완료**가 켜지고, 누르면 보호기 설정을 기기로 보내고 앞 화면으로 돌아간다. 바꾼 게 없으면 완료가 꺼져 있다.
10. 구 펌웨어 기기(지원 표시 없음)는 문구 줄만 쓰고, 전원·보호 사진·꺼짐 예약 줄은 흐리게 + "기기 업데이트 후 쓸 수 있어요"(§7 D8).
11. 기기가 오프라인이면 문구 화면과 같은 규칙 — 스위치·완료가 막히고 "기기가 연결돼 있지 않아 지금은 보낼 수 없어요".

## 3. 화면별 명세

### 3-1. 홈 진입 줄 (`HomeLcdRow` 수정)

### 3-2. 모듈 화면 설정 (신규, Figma `1659:5964`)
- 393 기준: 상단 헤더 0~106 `#FAFAFA`(뒤로 + 제목 16/700), 본문 `#F4F4F4`, 콘텐츠 x24 w345, 묶음 r16 흰 면, 줄 높이 48, 묶음 사이 24(y130 / y202 / y324). 줄 글자 18/600, 오른쪽 값 16/500. 각주 14/500 y429. 스위치 활성색 = Figma 빨강(구현 시 노드에서 색 실측 — VIVA 변수 확인).
- 제목 줄 표기 `화면 전원 · 켜짐|꺼짐`, `화면 보호 사진 설정` 오른쪽 `켜짐|꺼짐`(서버 `lcd_saver.enabled`, null이면 꺼짐).
- `꺼짐 시간` 오른쪽은 `H:mm~H:mm` 24시간(Figma 그대로 `20:00~8:00`). 시간은 Figma에서 예약 스위치가 꺼져 있어도 같은 모양 → 꺼져 있어도 편집 가능.
- 상태 표시 보강(Figma 밖, D1 확정): 꺼짐 예약이 켜져 있고 폰의 KST 시각이 예약 시간 안이면 전원 줄 아래 14/500 보조 글자로 "지금은 꺼짐 예약 시간이라 {종료}에 켜져요"(전원 꺼짐이면 표시하지 않음 — 이미 꺼짐). 그릴 때·앱 복귀 때만 계산(경계 타이머 없음, §11). 판정은 서버 확정값 기준, 예약 명령 대기 중엔 숨김.
- 전원 끄기 문구(가이드 §3-1): 꺼짐 상태에서 전원 줄 아래 "다시 켤 때까지 꺼져 있어요".

### 3-3. 화면 꺼짐 시간 (신규, Figma `1659:6267`)
- 시작(y118)·종료(y282) 두 블록. 각 블록: 오전/오후 세로 토글(선택=빨강 면 흰 글자), 시 칸, `:`, 분 칸(24/600, 회색 면), 칸 위아래 화살표.
- 시 1~12 순환, 분은 **10분 단위**(00·10·…·50 순환, D3). 서버 값이 10분 단위가 아니면(웹 등) 그대로 표시하고 화살표를 누르면 가까운 10분 칸으로 맞춘다. 완료 CTA y696(플로팅).
- 완료 활성 = 시작≠종료 AND 바뀜. 예약이 꺼져 있으면 폰 기억값에만 저장(오프라인에서도 가능). 시작>종료는 자정 넘김으로 정상.
- 오전/오후는 독립 토글, 시 화살표는 12↔1을 순환해도 오전/오후를 바꾸지 않는다.
- 서버로는 KST `HH:MM` 24시간으로 변환해 보낸다(서버가 분+tz로 기기에 전달).

### 3-4. 화면 보호 사진 설정 (신규, Figma `1659:6396`·`1660:6700`)

### 3-5. 모듈 화면 표시 문구 (기존 화면 소폭 수정)
- Figma에 입력칸 아래 안내 "중복되지 않는 이름으로 설정해 주세요"(12/500, y432)가 생겼다 → 안내만 추가, 중복 검사는 하지 않는다(D11).

### 3-6. 사진 자르기 (신규, Figma 밖 — D5)
- 사진첩에서 고른 직후 전체 화면. 어두운 바탕 위 **5:4 고정 틀**, 사진을 끌고 두 손가락으로 확대해 맞춘다. 상단 헤더는 다른 관리 화면과 같은 `ManagementTopBar`(뒤로 = 취소, 제목 "사진 자르기"), 하단 플로팅 CTA "완료"(다른 화면과 같은 369×56 r12).
- 완료 → 자른 결과를 JPEG로 만들어 업로드(긴 변 최대 1280px, 품질 90 — 기기는 160×128이라 충분, 5MB 상한과 멀다).
- 순수 Dart 자르기 패키지 사용(네이티브 Activity 등록이 필요한 `image_cropper`는 쓰지 않음). 패키지는 구현 때 유지보수 상태를 보고 고른다(후보 `crop_your_image`).
- 디자인이 없으므로 수치 검수 대상은 공통 부품(헤더·CTA)만, 나머지는 사용자 확인으로 확정.

## 4. 서버 계약 매핑

| 동작 | 호출 | 성공 판정 |
|---|---|---|
| 상태 읽기 | `GET /devices/{id}/lcd` (진입 시 1회 + `lcd_image_key` 변경 시) | — |
| 실시간 상태 | 기존 `devices` 행 UPDATE 구독(`deviceLinkStatusProvider`)에 `lcd_power`·`lcd_quiet_*`·`lcd_saver`·`lcd_image_key`·`lcd_image_set_at`·`lcd_updated_at` 추가 파싱 | 서버 확정값 = 진실 |
| 전원 | `PUT …/lcd/power {on}` | 명령 행 `result == ok` (`LCD_ON/OFF`) |
| 꺼짐 예약 | `PUT …/lcd/quiet {start,end}` / `DELETE …/lcd/quiet` | `LCD_QUIET` / `LCD_QUIET_CLR` |
| 보호기 | `PUT …/lcd/saver` **5개 필드 항상 전부** (`mode:"rotate"`, `show_offline_icon`은 서버 값 유지·없으면 true) | `LCD_SAVER` |
| 사진 | `POST …/lcd/image` multipart `file` (≤5MB JPEG) / `DELETE …/lcd/image` | `LCD_IMG` (최대 30초) / `LCD_IMG_CLR` |
| 지원 여부 | `devices.capabilities.lcd_saver == true` | — |

- 모든 쓰기는 201 `{id, action, status:"pending"}` → 그 `commands` 행을 id로 구독해 결과를 본다(사육장 재시작 `rebootProvider`와 같은 방식). 성공은 `result == ok`만. `no_ack`/`expired`/`lost`/`device_offline` = 기기에 안 감, `unknown_action` = 구 펌웨어, `busy`·`dl_*`·`http_401/404`·`sha_mismatch`·`flash_write`·`no_token`은 가이드 §4 문구.
- 400 `unsupported_firmware`는 안내 문구로 바꿔 보여주고 원문을 노출하지 않는다.
- 새 action 6종(`lcd_power`·`lcd_quiet`·`lcd_quiet_clear`·`lcd_saver`·`lcd_image`·`lcd_image_clear`)은 차트 마커·제어 기록에 **넣지 않는다**(`lcd_bitmap`과 같은 규칙, 모르는 action은 이미 무시됨 — 테스트로 고정).
- 사진: `image_picker`(설치됨)로 고르고 `maxWidth/maxHeight`·`imageQuality`를 줘서 JPEG로 받는다(iOS HEIC → JPEG 변환, 5MB 이하). `TerraRestClient`에 multipart POST 추가(같은 인증·오류 규칙).

### 확인 대기 표시
- 스위치(전원·예약)는 누르면 **목표 상태 + shimmer**, 그 줄만 잠금. 기존 사육장 제어(`control_pending`)와 같은 문법이지만 LCD 명령은 기기 제어를 잠그지 않는다(별개 큐가 아니라 같은 기기라 `busy` 가능성은 있음 — 실기 확인 항목).
- 결과 안내는 화면이 루트 전체 화면이므로 `ControlFeedback`(Overlay)을 쓴다.

## 6. Figma ↔ 서버 충돌

| # | Figma | 서버/펌웨어 (가이드) | 영향 |
|---|---|---|---|
| C1 | 꺼짐 예약 중에도 **전원을 켤 수 있다** | `화면 켜짐 = 전원 ON AND NOT 예약 시간` — 예약 시간엔 전원이 켜짐이어도 꺼져 있다 | 앱 스위치는 켜짐인데 LCD는 꺼진 상태가 생긴다 |
| C2 | 예약 중 껐다면 **종료 시각에 다시 켜짐** | 전원 끄기는 **끈끈함(sticky)** — 예약이 끝나도 안 켜지고 켜기로만 풀림 | 디자이너 예시(21시 켬→끔→8시 켜짐)와 반대로 동작 |
| C3 | 예약 스위치를 꺼도 시간 줄은 그대로 보임(기본 20:00~8:00) | 해제는 `DELETE` → 서버 값 NULL, 시간이 남지 않는다 | 끄고 다시 켤 때 시간을 앱이 기억해야 한다 |
| C4 | 보호기 모드 선택 없음(번갈아 표시만), 오프라인 아이콘 설정 없음 | `mode: rotate|image`, `show_offline_icon` | 범위 밖으로 두면 문제 없음 |
| C5 | 사진 노출 1~5분 | `image_sec` 5~300초, 서버 기본 20초 | 미설정 기본값은 Figma(1분/10초). 칸에 안 맞는 서버값(20초 등)은 **실제 값 그대로 표시**, stepper를 처음 누를 때 칸으로 맞춤(§11) |
| C6 | 자르기 화면 없음 | 서버가 가운데 cover 크롭, "업로드 전 5:4 크롭 UI 권장" | 세로 사진은 가운데 띠만 남는다 |

## 11. 교차 검수 반영 규칙 (2026-11-03, 본문보다 우선)

### 11-1. 상태 읽기
- 진입 시 `GET /lcd` + 기기 행 재조회(`capabilities` 최신화). 불러오는 동안 shimmer, 실패면 재시도 안내, **불러오기 전엔 모든 쓰기 막음**(기본값으로 기존 설정을 덮지 않게).
- 실시간 파싱에 `capabilities.lcd_saver` 추가 — OTA로 지원이 켜지면 열린 화면도 활성화.
- `lcd_saver`는 `==`가 있는 값 객체로 파싱(3초마다 오는 기기 행이 중복 갱신을 일으키지 않게).

### 11-2. 확인 대기 (전원·예약·보호기·사진 공통)
- 201 응답의 명령 id로 그 `commands` 행을 **1회 조회한 뒤 구독**(구독 전에 끝난 명령 회수).
- ok가 와도 `devices` 확정값이 목표와 같아질 때까지(최대 ok 뒤 3초) 목표 상태 유지 — 스위치가 뒤로 튀지 않게.
- 8초 무응답 = "응답이 늦어요"(대기 유지), 서버 30초 판정에서 확정. 사진은 30초 판정까지 "기기로 보내는 중".
- 결과 문구: `expired`·`device_offline` = "기기에 전달되지 않았어요" / `no_ack` = "기기 응답을 받지 못했어요" / 422·`bad_request`·503 = "설정을 보내지 못했어요" / 400 `unsupported_firmware` = "기기 업데이트가 필요해요" / 사진 실패는 가이드 §4 문구. 모두 `ControlFeedback`.
- 같은 종류 명령은 한 번에 하나: quiet 대기 중엔 예약 스위치와 꺼짐 시간 줄을 함께 잠근다.

### 11-3. 꺼짐 예약
- 시간의 진실: **서버 값이 있으면 서버**(폰 기억값도 덮어씀) → 없으면 폰 기억값 → 없으면 20:00~08:00. 예약을 끌 때(DELETE 성공) 직전 시간을 폰에 기억.
- 각주: 전원 켜짐이면 Figma 문구 "설정한 시간 동안 화면을 끄고, 이후 자동으로 다시 켜집니다", 전원 꺼짐이면 "다시 켤 때까지 꺼져 있어요"로 바꿔 보인다.
- "지금은 꺼짐 예약 시간이라 {종료}에 켜져요"는 그릴 때·앱 복귀 때만 계산, quiet 명령 대기 중엔 숨김.

### 11-4. 화면 보호기
- 진입 시 값을 기준선으로 잡고, 편집 중 들어오는 실시간 값은 초안을 덮지 않는다. 저장 안 한 변경은 뒤로 가면 버린다.
- 칸에 안 맞는 서버값은 실제 값 그대로("20초", "7초") 표시, stepper를 처음 누를 때 가장 가까운 칸으로 맞추고 그때부터 '바뀜'. 스위치만 바꾸면 시간은 서버값 그대로 보낸다.
- `mode`는 서버 값 그대로 보낸다(없으면 rotate) — 기존 `image` 기기를 몰래 바꾸지 않음. `image`면 각주를 "모듈 화면에 사진만 표시돼요"로.
- 사진 '있음' = 서버 `lcd_image_key` 있음(ACK 뒤). 없으면 보호기 **켜기만** 막고 끄기는 허용, 설정 화면 줄 오른쪽은 "사진 없음".
- 사진 명령 대기 중엔 완료를 막는다(기기 다운로드와 보호기 명령이 겹치지 않게). 완료 뒤 대기는 설정 화면의 '화면 보호 사진 설정' 줄 shimmer, 대기 중 재진입은 편집 잠금.

### 11-5. 사진
- 실패는 '원위치'가 아니다 — 기기는 이전 사진을 먼저 지우므로 "기기에 사진이 없을 수 있어요, 다시 올려 주세요". 서버 key 처리는 요청서 §5로 질의, 회신 전엔 실패 뒤 `GET /lcd` 재조회 결과를 그대로 표시.
- 업로드·명령 대기는 진행 중 keepAlive(`rebootProvider` 방식) — 화면을 나가도 끝까지, 결과는 화면 밖에서도 알린다.
- 사진첩 단계에서 긴 변 2048로 줄여 받고, 자른 뒤 JPEG 인코딩(긴 변 1280, 품질 90)은 isolate. EXIF 회전 반영 확인.

### 11-6. 오프라인
- 스위치·완료에 더해 **사진 칸·연필 메뉴도 막는다**. 예약이 꺼진 상태의 시간 편집(폰 기억)은 허용.

### 11-7. 기타
- 문구 글자 수는 지금처럼 20자(`lcd_setting_tile.dart`), 변경 없음.
- `erase_flash` 등 기기-서버 불일치는 화면에 상시 문구를 두지 않는다(검수 기각, 드문 운영 사고).

### 11-8. 계약 스파이크 (단계 ①.5)
- 조건: 서버 재배포 확인 + 앱에서 접근 가능한 `capabilities.lcd_saver=true` 온라인 기기(운영 DB상 `terra-d9feaaa2` 1대 — 계정 확인 필요).
- 실측: PUT power·quiet, POST image(성공 1·기기 끈 상태 실패 1), 사진 수신 중 PUT saver → `commands` 결과 시점, `devices` 실시간에 새 컬럼이 실리는지와 ok 뒤 지연, 실패 뒤 `lcd_image_key`, 겹침 결과. 결과에 따라 §11-2·11-5 수치 조정.
