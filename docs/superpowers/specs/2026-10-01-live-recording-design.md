# 라이브 직접 녹화 기획 (초안, 2026-10-01)

> 상태: **기획 초안 — 구현 전, 미결 항목 확정 필요.** Figma 밖 기능(사용자 결정).

## 1. 확정된 결정 (2026-10-01 사용자)

| 항목 | 결정 |
|---|---|
| 방식 | 앱이 받은 WebRTC 영상을 그대로 녹화(flutter_webrtc `MediaRecorder`) — 화면 녹화·서버 녹화 아님 |
| 버튼 위치 | **가로 전체화면 라이브(`/crecam/cameras/:id/live`)에만** |
| 길이 | 누른 순간부터 **60초 고정**, 자동 종료 |
| 보관 | **앱 안 보관함(북마크) + R2 업로드** |
| 끊김 | 끊기기 직전까지 저장 + 안내 |

## 2. 사용자 체험 흐름

1. **[화면]** 가로 전체화면 라이브, 영상이 나오는 중(`streaming`). 우측에 녹화 버튼(빨간 원).
   영상이 아직 안 나오거나(`connecting`·`recovering`·`failed`·`limited`) 시청 제한 종료까지 60초 미만이면 버튼 흐림.
2. **[조작]** 녹화 버튼 탭.
   **[반응]** 버튼이 정지 아이콘으로 바뀌고 상단에 `● REC 0:42` 남은 시간 카운트다운 + 둘레 진행 링.
   **[감정]** "지금 찍히고 있구나"가 분명해야 한다.
3. **[조작]** 기다리거나, 정지 버튼으로 일찍 끝냄(→ 미결 Q1).
   **[반응]** 60초가 되면 자동 종료 → 알약 안내 "녹화 저장 중…" → "보관함에 저장했어요 · 보기".
4. **[반응]** 업로드는 뒤에서 진행. 화면을 나가도 계속되고, 실패하면 보관함 카드에 "업로드 대기·다시 시도" 표시. 로컬 파일은 업로드 전에도 보관함에서 재생된다.
5. **끊김:** 연결 끊김·`stalled`·15분 제한·다른 기기로 시청 전환·화면 이탈·앱 백그라운드 → 그 시점까지 저장, 안내 "연결이 끊겨 N초까지 저장했어요". 3초 미만이면 버린다(→ Q4).

## 3. 기술 구조

- **녹화:** `MediaRecorder.start(path, videoTrack: 원격 트랙)` → 60초 타이머 → `stop()`. 오디오 없음(카메라 무음).
  ⚠️ **iOS 원격 트랙 녹화 지원이 불확실** — 구현 전 **선행 검증(§5 0단계)** 필수. 안 되면 iOS는 버튼 숨김으로 출시하고 Android 먼저.
- **녹화와 시청 로직 분리:** `LiveRecordingController`(신규, my_cage/presentation)가 `WebRtcLiveController` 상태를 구독해 끊김 시 정지. 세대(`_gen`)가 바뀌면 그 녹화는 종료(이어 붙이지 않음).
- **보관함 연동:** 현 북마크는 `motion_clips.clip_id` 기준(`FavoriteClip` 로컬 mp4 + `favorite_clips` 클라우드). 직접 녹화는 서버 행이 없으므로 **서버가 녹화 행을 만들어 id를 줘야** 같은 보관함에 섞을 수 있다.
- **R2 업로드:** 앱에는 R2 쓰기 권한이 없다 → 서버 요청 필요(§4).
- **썸네일:** 녹화 끝에 첫 프레임 로컬 생성, 함께 업로드.

## 4. 서버 요청 (petcam / terra-server)

1. `POST /recordings` → `{recording_id, upload_url(presigned PUT), thumb_upload_url}` — 카메라 소유 확인.
2. 업로드 완료 `POST /recordings/{id}/complete` (크기·길이·started_at).
3. 저장 위치: `motion_clips`에 `source='manual'`로 넣을지 별도 테이블일지 → 하이라이트 규칙·전체 영상 목록에 섞일지와 직결(Q3).
4. 보관 기간·용량 한도·삭제 API.

## 5. 단계

0. **선행 검증(반나절):** Android·iOS 실기기에서 원격 트랙 60초 녹화 → 파일 재생 확인. 결과로 iOS 범위 확정.
1. 로컬 녹화 + 보관함 로컬 표시(서버 없이 동작).
2. 서버 계약 확정 후 R2 업로드·클라우드 보관함.
