# Clarity 정책의 쉬움·단순함 평가

2026-09-12 · 평가 대상: [Clarity 정책](clarity-policy.md)

**평가 질문: 개발 지식이 없는 기획자가 이 문서만 읽고 목적·판단 기준·자기 할 일을 이해할 수 있는가?** Clarity 사용 절차를 점검하는 체크리스트가 아니라, 정책 문서 자체를 평가하는 체크리스트다.

## 1. 평가 체크리스트

각 질문에 ‘통과 / 보완 필요 / 미통과 / 확인 전’으로 답하고 근거를 적는다. 단순히 문서가 짧아졌다고 통과시키지 않는다.

- [ ] 첫 부분에서 무엇을 알아내려는지 설명할 수 있는가?
- [ ] 코드·수식·개발 용어를 몰라도 핵심 내용을 이해할 수 있는가?
- [ ] 처음 읽을 때 알아야 할 내용이 먼저 나오고 세부 설명을 뒤질 필요가 없는가?
- [ ] 읽고 나면 기획자가 첫 행동을 고를 수 있는가?
- [ ] 기획자와 개발·운영 담당자가 할 일이 분명히 나뉘는가?
- [ ] 사용량과 선호, 시도와 성공을 혼동하지 않게 설명하는가?
- [ ] 현재 가능한 일과 제안·미구현 사항을 구분하는가?
- [ ] 분석 결과를 짧게 남기고 다음 개선으로 연결할 수 있는가?
- [ ] 실제 기획자가 추가 설명 없이 목적·할 일·주의점을 자기 말로 설명했는가?

마지막 항목은 실제 기획자 확인이 있어야 통과다. 문서 작성자의 자체 평가로 대신하지 않는다.

## 2. 기존 정책 평가

기준 원본은 `fab13a2` 커밋의 `docs/clarity-policy.md`다. 작성자가 체크리스트로 평가한 결과이며 실제 기획자 사용성 검증 결과는 아니다.

| 평가 기준 | 이전 판정 | 근거 | 개선 후 자체 점검 |
|---|---|---|---|
| 목적이 바로 보임 | 통과 | 첫 절에 합의한 목적과 세 질문이 있었음 | 통과 — 첫 절의 세 질문 표 유지 |
| 개발 지식 없이 이해 | 미통과 | SDK API·이벤트명·집합 수식·스키마 설명이 본문에 혼재 | 통과 — 일상어로 다시 쓰고 필요한 용어 두 개만 설명 |
| 핵심을 먼저 읽음 | 미통과 | SDK 경계·단계별 시나리오·기능 명세를 지나야 주간 운영이 나옴 | 통과 — 목적 → 해석 → 할 일 → 담당 → 현재 상태 순서 |
| 첫 행동을 고를 수 있음 | 보완 필요 | 주간 운영은 있었으나 뒤쪽에 배치 | 통과 — ‘질문 하나 고르기’와 실제 질문 예시 명시 |
| 담당 역할이 분명함 | 보완 필요 | 운영자 역할은 있었으나 기획자·개발자의 책임이 여러 절에 흩어짐 | 통과 — 담당별 표 하나로 정리 |
| 잘못된 해석을 방지 | 통과 | 자동 재생·만족도·성공 상태·수집 누락을 구분함 | 통과 — 핵심 다섯 규칙으로 압축 |
| 현재와 제안을 구분 | 통과 | 초안 상태와 구현·검증 여부를 표시함 | 통과 — 상단 상태와 마지막 준비 현황 표 유지 |
| 결과를 쉽게 남김 | 미통과 | 여러 항목을 나열했으나 정책만으로 간단히 채울 양식이 없었음 | 통과 — 사실·해석·개선·재확인 네 줄 |
| 실제 기획자 이해 확인 | 확인 전 | 확인을 수행하지 않았음 | 확인 전 — 문서 수정만으로 검증됐다고 하지 않음 |

**이전:** 통과 3 / 보완 필요 2 / 미통과 3 / 확인 전 1.

**개선 후 자체 점검:** 문서에서 확인할 수 있는 8개 기준은 충족하도록 수정했다. 실제 기획자 이해 여부 1개는 확인 전이다.

## 3. 평가를 어떻게 반영했나?

- 기획자 본문에서 코드·수식·이벤트 목록·초 단위 측정 조건을 걷어냈다. 후속 구현 시 기술 명세를 따로 확정해야 하며, 과거 제안은 Git 이력에서 확인할 수 있다.
- ‘얼마나 많이 썼나’와 ‘좋아하나’를 다른 질문으로 유지했다. 쉬워 보이려고 해석상의 차이를 없애지 않았다.
- 개인정보 보호·수집 시작 미확정·현재 미구현 상태를 유지하면서 담당자가 해야 할 일로 정리했다.
- 10개 대단원 대신 5개로 줄이고, 기획자가 남길 결과는 네 줄로 정했다.
- 요청을 잘못 이해해 만들었던 별도의 운영 체크리스트는 이 평가 문서로 교체했다.

## 4. 마지막 확인 방법

기획자가 정책을 읽은 후 ‘Clarity로 무엇을 알아내나?’, ‘나는 무엇을 하나?’, ‘지금 바로 할 수 없는 일은 무엇인가?’를 설명하게 한다. 막히거나 다르게 해석한 문장이 있으면 그 문장을 다시 고친다. 이 확인은 아직 수행하지 않았다.
