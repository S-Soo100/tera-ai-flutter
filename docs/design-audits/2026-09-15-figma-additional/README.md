## 2. 그룹 삭제 버튼 추가

원본 `781:2349`. [원본 이미지](781-2349.png)

- 그룹 상세 하단의 완료56px 아래에 빨강 ‘이 그룹 삭제’56px 버튼.
- 그룹 설정의 ‘그룹에서 제외’, 기기 상세의 ‘이 기기 삭제’와 다른 대상이다.
- 현재 `RedesignGroupRepository`에는 saveGroup/rename/removeMember/unlink만 있고, 그룹 전체 삭제를 호출하는 메서드는 없다. 이 확인만으로 운영 서버에 삭제 API가 없다고 단정하지 않는다.
- **기능 결정 필요:** 삭제 확인 문구, 그룹 삭제 후 구성원의 귀속, 연결·기기·개체 보존, 서버 원자성/권한/재시도 계약.
- 검토 권장안: 그룹만 제거하고 구성원은 그룹 없음으로 이동, 기기·개체 및 데이터는 보존. 이 내용은 Figma에서 확인한 사실이 아니라 제안이며 사용자 승인 전 실행하지 않는다.
- 여러 removeMember 호출로 그룹 삭제를 흉내 내면 중간 실패로 일부만 해제될 수 있으므로 전용 계약 확인 없이 채택하지 않는다.

## 3. 카메라 미연결 MyCre 화면

별도 섹션 `781:2022`, 화면 `781:2064`. [원본 이미지](781-2064.png)

- 개체 프로필 아래 문구: ‘카메라와 연동해 활동 리포트를 받아보세요’.
- 빨강 CTA: ‘+ 카메라와 그룹만들기’.
- 일간/주간 그래프의 격자는 유지하고 막대는 비운다.
- 총 활동/평균 예시는 모두 `0h 0m`.
- **계획 영향:** 개체 없음과 구별되는 카메라 미연결 상태·그룹 만들기 진입점 검토를 추가한다.
- **기존 결정과 구분 필요:** 카메라가 연결됐지만 관측 정보/평균 근거가 부족한 경우는 `--` 유지. ‘아예 카메라와 연결되지 않은 상태’에만 Figma `0h 0m`을 사용할지 별도 확정한다. 서버 실패나 관측 결측을0으로 표시하지 않는다.
- CTA에서 현재 개체를 선택한 채 기존 그룹 생성·카메라 선택 흐름으로 이어가는 것을 제안한다. 이름만으로 새 라우트나 저장 동작을 확정하지 않는다.
