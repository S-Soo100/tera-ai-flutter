# 추가 Figma 기능 확정 — 2026-09-15

상태: 사용자가 그룹 삭제안과 미연결 MyCre 표시안을 각각 ‘승인’으로 확정했다. 기능 결정 기록이며 구현·서버 배포 완료를 뜻하지 않는다.

## 그룹 삭제

- 그룹만 삭제한다. 소속 사육장·카메라·도마뱀은 모두 ‘그룹 없음’으로 이동한다.
- 기기 등록, 계정 소유권, 개체 정보, 영상, 메모는 유지한다. 구성원 사이의 그룹 소속 연결만 해제한다.
- 확인 문구: **“이 그룹을 삭제할까요? 소속 기기와 개체는 삭제되지 않고 ‘그룹 없음’으로 이동합니다.”**
- 확인창 버튼: **취소 / 삭제**.
- 취소하면 아무 데이터도 변경하지 않는다.
- 그룹 삭제와 모든 구성원의 소속 해제를 한 번에 처리한다. 실패하면 기존 그룹과 전체 소속을 유지하며 일부만 해제된 성공 상태를 만들지 않는다.
- 원자적 처리 요구는 확정됐다. 실제 API 이름·권한·재시도 계약과 서버 배포 여부는 구현 전 확인 대상이다. 기존 removeMember 여러 번 호출로 대체하지 않는다.

체험: [화면] 그룹 상세 ‘이 그룹 삭제’ → [조작] 탭 → [반응] 위 확인창 → [조작] 삭제 → [반응] 성공 시 그룹 제거·구성원은 그룹 없음, 실패 시 기존 상태 → [감정] 기기와 개체가 사라지지 않음을 이해한다.

## MyCre 활동 표시 범위

| 상태 | 총 활동·평균 표시 | 화면·저장 규칙 |
|---|---|---|
| 선택한 개체에 연결된 카메라가 없음을 확인함 | 일간·주간 모두 `0h 0m` | Figma 빈 그래프와 ‘카메라와 그룹만들기’ 버튼. 초기 화면 표현이며 측정 기록으로 저장하지 않음 |
| 카메라는 연결돼 있으나 오프라인·조회 실패·관측 정보 부족으로 값을 확인할 수 없음 | 확인 불가능한 값만 `--` | 연결 없음으로 취급하지 않음. 확인된 기존 값까지 일괄 지우지 않음 |
| 정상 관측 결과 활동이 실제로 없음 | 확인된 총 활동은 `0h 0m`; 평균도 정상 집계 근거가 있으면 `0h 0m` | 실제 관측 결과. 총 활동을 알더라도 평균 근거가 없으면 평균은 `--` |

- ‘미연결’은 개체와 카메라의 소속 관계가 없는 상태이다. 네트워크 오프라인이나 연결 정보 조회 실패와 구분한다.
- 관계 정보를 읽는 중이거나 실패해 연결 여부를 모르면 ‘미연결0’ 분기를 선택하지 않는다.
- 안내 문구: **‘카메라와 연동해 활동 리포트를 받아보세요’**. 버튼: **‘카메라와 그룹만들기’**(Figma plus 아이콘 포함).
- 미연결 초기 표시를 Hive·Supabase·API에 활동 데이터로 쓰거나 평균 계산에 넣지 않는다.
- 선택 개체의 프로필, 일간·주간 날짜와 빈 격자를 유지한다. 개체가 아예 없는 화면은 기존 개체 없음 흐름을 유지한다.

체험: [화면] 카메라 미연결 개체의 프로필·연결 안내·0h0m·빈 그래프 → [조작] 카메라와 그룹만들기 → [반응] 기존 그룹 연결 절차로 진입. 연결된 카메라의 통신 오류는 별도로 실패/미확인 상태를 보여 실제 활동0으로 오해하지 않게 한다.

## 검증 항목

- 그룹 삭제 취소0회 쓰기, 성공 시 전원 등록·개체·영상·메모 보존, 실패 시 그룹/소속 전체 유지.
- 미연결, 연결 정보 로딩/실패, 연결된 카메라 오프라인, 관측 결측, 정상 무활동, 총 활동만 확인 가능하고 평균 미확인 상태를 각각 검사.
- 미연결과 연결됨 사이 상태 전환 시 초기 표시0이 실제 데이터나 캐시에 남지 않음.

드롭다운의 추가 디자인 및 나머지 수정항목의 승인 상태는 이 두 기능 승인만으로 확대하지 않는다.
