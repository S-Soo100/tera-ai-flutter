# 글자 간격 수정 — iPhone 13 mini ↔ Figma 대조 (2026-11-09)

어절 줄바꿈 문구의 자간 두 배 적용(0.175.4~0.175.6)을 고친 화면을 시뮬레이터에서 찍어 Figma와 나란히 저장했다. `compare/`의 이미지 왼쪽이 Figma, 오른쪽이 앱이다.

- **기기:** iPhone 13 mini 시뮬레이터(iOS 26.4). Flutter 논리 폭 375×812.
- **배율:** 시뮬레이터 스크린샷은 1pt=2.88px(1080×2340)이다. Figma(3배)와 같은 크기로 보이도록 앱 이미지를 104.17% 키워 붙였다.
- **Figma 프레임은 393pt 폭**이고 앱은 375pt 폭이다. 그래서 줄바꿈 위치가 다른 곳은 기기 폭 차이다(아래 표 "폭 차이").
- **데모 값:** "임시 위젯"은 디버그 빌드 전용 `/design-test/text-check`에서 실제 위젯·실제 `ko.json` 문구를 데모 데이터로 띄운 것이다.

## 대조에서 찾아 고친 것

1. **[수정] 화면 꺼짐 시간 — 393pt보다 좁은 폰에서 분 칸이 18px 넘침.** 칸 폭이 고정이라 375pt 폭에서 잘렸다. 좁은 폰에서만 시·분 칸이 줄어들게 고쳤다(375pt에서 칸 99, 393pt 이상은 Figma 값 108 유지). 재현 테스트 추가.
2. **[수정] 화면 꺼짐 시간 제목.** Figma "화면 꺼짐 시간 예약"에 맞췄다(앱은 "화면 꺼짐 시간"이었다).

## Figma와 달라도 유지한 것 (이전 결정)

- 사진 노출 시간 기본값 1분 — Figma 표기 10초와 다르다. 기획 C5(미설정 기본 1분/10초), 단위 D3.
- 사진이 없을 때 스위치 비활성 + "사진을 먼저 추가해 주세요" — 기획 D9.
- 완료 버튼 — 값이 바뀌기 전에는 비활성(Figma 시안은 활성 상태를 그림).

## 확인하지 못한 것

- **16번 사진:** 미리보기는 서버 URL이 있어야 그려져 데모에서는 회색이다. 연필 버튼·메뉴 위치만 대조했다.
- 임시 위젯으로 띄운 화면은 실제 서버 응답으로 열어 본 것이 아니다. 실기기·실데이터 확인은 02번만 했다.
- 실제 폰(물리 기기)은 확인하지 않았다.
- Figma 프레임 폭(393)과 달라, 393 폭 기기의 줄바꿈까지 시뮬레이터로 대조하지는 않았다.
