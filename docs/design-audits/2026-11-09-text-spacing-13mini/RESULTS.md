# 글자 간격 수정 — iPhone 13 mini ↔ Figma 대조 (2026-11-09)

어절 줄바꿈 문구의 자간 두 배 적용(0.175.4~0.175.6)을 고친 화면을 시뮬레이터에서 찍어 Figma와 나란히 저장했다. `compare/`의 이미지 왼쪽이 Figma, 오른쪽이 앱이고, 머리글과 파일 이름 끝(`_real`/`_temp`)에 출처를 적었다.

- **기기:** iPhone 13 mini 시뮬레이터(iOS 26.4). Flutter 논리 폭 375×812.
- **배율:** 시뮬레이터 스크린샷은 1pt=2.88px(1080×2340)이다. Figma(3배)와 같은 크기로 보이도록 앱 이미지를 104.17% 키워 붙였다.
- **Figma 프레임은 393pt 폭**이고 앱은 375pt 폭이다. 줄바꿈 위치가 다른 곳은 기기 폭 차이다.
- **촬영 순서:** 실제 계정의 실제 페이지를 먼저 열었다. 임시 위젯(디버그 빌드 전용 `/design-test/text-check`)은 아래 사유로 열 수 없는 상태만 썼다. 실제 위젯·실제 `ko.json` 문구에 데모 값만 넣었다.
- **빌드:** 수정 코드가 든 디버그 빌드다. 버전 번호를 올리기 전에 빌드해 앱 안 표기는 0.175.6(497)이다.
- 촬영 중 기기로 명령을 보내거나 설정을 바꾸지 않았다. 재시작 확인창은 취소로 닫았다.

## 대조에서 찾아 고친 것 (0.175.7)

1. **화면 꺼짐 시간 — 393pt보다 좁은 폰에서 분 칸이 18px 넘침.** 칸 폭이 고정이라 375pt 폭에서 잘렸다. 좁은 폰에서만 시·분 칸이 줄어들게 고쳤다(393pt 이상은 Figma 값 108 유지). 재현 테스트 추가.
2. **화면 꺼짐 시간 제목.** Figma "화면 꺼짐 시간 예약"에 맞췄다.
