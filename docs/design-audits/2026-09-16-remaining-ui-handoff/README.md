`figma/`는 디자이너 원본 채널 axfr9s1n에서 이번에 내보낸 PNG다. `specs/`는 같은 시점의 상대 좌표·서체·색상·반경과 원본 섹션 정보다. `app/`는 코드 기준 커밋에서 생성한 52개 제품 위젯 캡처다. 이미지 수는 중복/파생 상태를 포함하며 독립 화면 수가 아니다.

원본은 Home, Camera, CreActivity, Main, 기기 연결v3, 마이페이지 섹션을 조회했다. 마이페이지에는 완성 프레임이 없고 메모만 있다. 버린 시안·v1/v2·기존 승인 화면 전체를 다시 구현하는 계획이 아니다. 기존 승인 중 그림자·구형 진입 경로 같은 미판정 항목은 P17/P18에 보존했다.

## 중요한 발견

1. 모프 검색 결과와 빈 결과의 X/강조/문구가 빠져 있다.
2. LCD와 개체 그룹 선택은 원본 전체 화면과 구조가 다르다.
3. 연결 단계의 CTA·대기·오류 표현이 원본과 다르다.
4. 제어/예약은 최신 원본의 여러 상태가 현재 구현에 없다. 기존 확정 기능과 충돌하는 동작은 별도 결정이 필요하다.
5. 하이라이트 목록의 전폭 카드/3열 그리드, 플레이어 가로 chrome·동작 순서 차이가 크다.
6. 주간 온습도 헤더의 내부 SVG 그림과 최대값 수치 색, 빈 화면 버튼, 메모 메뉴 등 세부 차이가 남아 있다.

## 이번 확인 결과와 한계

- 기존 화면 캡처 실행: 14개 통과, 1개 실패. 실패는 기존 테스트가 사진 편집 SVG의 **프레임24**를 기대하지만 승인된 구현이 **프레임36/내부그림18**인 오래된 기대값이다. 큰 종 이름 자체가 잘렸다고 단정하지 않는다. P18에 처리 지시를 남겼다.
- 추가 온습도/플레이어/제어/예약/LCD 캡처: 4개 통과.
- 하이라이트/북마크/달력 및 밝기 지원 재촬영: 2개 통과.
- 연결 15개 상태 캡처 시나리오: 1개 통과.
- 모프 검색·그룹 선택 추가 캡처 시나리오: 1개 통과.
- 임시 테스트는 앱 코드에 남기지 않았고 재현 소스 `.dart.txt`와 실행 로그를 `reproduction/`에 보관했다. 재실행은 각 파일의 원래 test 폴더 위치를 유지해 복사한 후 실행한다.
- 이번에는 앱 수정·새 빌드·시뮬레이터 설치·운영 쓰기를 하지 않았다. 실제 OS 키보드, BLE/기기 연결, 서버 배포, 그림자 수치는 최종 검증이 아니다.
- 데이터에 따라 달라지는 그래프 곡선, 썸네일, 장치명과 날짜는 원본 예시로 고정하지 않는다. mock 영상 영역의 회색 placeholder는 네트워크 결함으로 보고하지 않는다.
- 현재 새 원본만 있는 상태는 동일 상태 앱 캡처가 없으므로 코드와 현재 진입 화면을 대조했다. 이를 UI 검수 완료/사용자 승인으로 처리하지 않는다.
