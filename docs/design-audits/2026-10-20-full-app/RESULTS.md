## 방법

1. talk-to-figma로 섹션 노드를 받아 화면마다 TEXT 노드의 굵기·크기·줄높이·자간·색, 면(fill·stroke·모서리)을 뽑았다.
2. Figma 글자를 `ko.json` 값과 맞춰 코드 위치를 찾고, 그 `Text`의 style 식을 괄호 짝으로 끊어 자동 비교했다.
   키가 공용 위젯(관리 화면 버튼·목록 행·입력칸·마이페이지 행 등)으로 넘겨지는 곳은 위젯 정의를 직접 읽었다.
3. 노드에 값이 없는 것(스피너·아이콘 글리프 색, 흰 막 투명도)은 export 이미지 픽셀로 쟀다.

## 차이가 남은 것 (고치지 않음 — 보고)

- **탭바 위 선 색**: Figma 안에서 #E3E3E3(30곳)과 #F4F4F4(17곳)가 섞여 있다. 앱은 #E3E3E3.
- **LED 타일 아이콘 원**: 홈 시안의 LED 원은 #E39B00인데 VIVA Yellow 변수는 #E89E00이다. 앱은 변수(#E89E00)를 쓴다.
- **가로 플레이어 시각 색**: 가로 시안 4곳 중 2곳 #626262, 2곳 #545454. 앱은 #545454 유지.
- **버튼 하나짜리 확인창 모서리**: 옛 시안 982:3537만 8이고 나머지는 12. 앱은 12.
- **마이페이지 목록 행 선**: 노드 데이터에 #E3E3E3 선이 남아 있으나 2026-10-04 사용자 결정(Figma 화면상 선 없음)대로 선 없이 둔다.
- **개체 정보 입력 줄높이**: 앱 19/16(=19.0) vs Figma 19.09 — 0.09pt 차이라 둔다.
- 메뉴 그림자는 talk-to-figma가 effect 값을 주지 않아 확인하지 못했다.
- 커뮤니티 화면은 Final Design에 섹션이 없어 대조하지 않았다. Figma 밖 요소(시스템 알림 꺼짐 안내, 라이브 재시작 버튼 등)도 대조 대상이 아니다.
