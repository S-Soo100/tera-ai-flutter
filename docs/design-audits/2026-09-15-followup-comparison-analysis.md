## 판정

주요 화면 구조와 앞서 고친 항목은 개선됐지만, **시각 일치 완료는 아니다**. 아래 6개 수정 항목이 남는다. 앱 코드·서버는 이번 분석에서 변경하지 않았다.

비교는 Figma 화면 폭 393px, 앱 캡처 1206px를 논리 폭 402px로 환산하여 수행했다. 화면을 같은 폭으로 강제 축소하지 않고 동일한 논리 픽셀 단위로 비교했다. 앱의 더 긴 뷰포트에 따른 하단 고정 버튼 위치 차이는 별도로 취급했다.

## 수정 오류로 분류하지 않은 차이

- 이름·모프·날짜·온습도·제어 이력·활동량은 로컬 가상 검수 데이터다. 실제 관식/크랑이 사육장 기록이 아니다.
- MyCre 일간 원본 예시의 최고 눈금210과 앱60은 단순 디자인 값 교체 대상이 아니다. 현재 앱은 시간당 활동분을 표시해 최대60분이다. 데이터 단위·집계 계약을 유지하면서 격자 디자인을 맞춰야 한다.
- 그룹명이 상단에 뜨는 것, 그룹 소속에 따른 슬롯색, 미연결 총량·평균4곳의0과 연결 CTA는 승인한 동작이다.
- 그룹 삭제 확인 문구는 승인한 문구를 우선한다. 운영 RPC 배포 여부는 시각 검수와 별개이며 아직 운영 완료로 판정하지 않는다.
- 앱 뷰포트402×874와 원본393×852 차이, 상태바와 안전영역, 고정 하단 버튼 위치 차이는 단순 픽셀 이동으로 보정하지 않는다.
- 라이브 연결 실패와 썸네일 빈칸은 검수 환경의 비연결 상태다. 영상 자체 픽셀은 비교 대상에서 제외한다.
- 미연결 날짜 이동 화살표는 원본과 다르지만 기존 날짜 탐색 동작에 관련된다. 이번 분석에서 임의 제거 대상으로 확정하지 않았다.
