## 원본 확인 방법

`기기 연결v3`(971:1590)의 체크박스52개를 PNG 3배율로 export했다. 기준4개(1063:6861/1063:6864/990:11302/990:11298)의 alpha 픽셀과 비교했고 **52개 모두 해당 계열과 차이0**이었다. 명칭이 단순 `check_box`인 노드도 실제 모양으로 분류했다. [분류 결과](checkbox-node-classification.json).

원본은 일부 화면에서 선택300·미선택400을 혼용한다. 이를400 또는300으로 일괄 통일하지 않았다. 선택한 도마뱀 카드(1043:6112) 역시300이지만 **해당 카드 선택 화면 자체가 현재 앱에 없어** 이번 단순 아이콘 교체에 포함할 수 없었다. 아래 후속1번으로 남긴다.

## 추가 발견 — 이번에는 변경하지 않음

### 1. 기기 연결 후 도마뱀 카드 선택 화면 누락

- 원본 `1043:5893`: ‘이 사육환경에서 어떤 도마뱀을 키울까요?’ + 사진·이름·성별·모프·체중 카드 + 선택300/미선택400 체크 + ‘이 사육 환경에서 키우기’ 버튼.
- 앱 `DeviceAddFlowScreen._petChoice`: 기존 개체/새 개체/나중에 바텀시트 후 그룹 상세 또는 개체 등록으로 이동한다.
- 수정 범위는 아이콘이 아니라 전용 선택 화면과 기존 개체 연결 경로다. 이미 승인된 한 그룹1마리·기존 개체 보존·그룹 연결 계약을 유지하며 구현해야 한다.

### 2. 기기 검색 목록의 면·선·신호 아이콘

- 원본 `990:7601`: #F4F4F4 목록 면, 항목 사이 구분선, RSSI 숫자 옆 신호 막대 아이콘.
- 앱 `_surface`는 입력 필드용 #FAFAFA를 사용하며 목록 행 구분선이 없다. RSSI는 숫자만 표시한다.
- 체크박스 계열과 색은 이번에 수정했다. 위 면·선·신호 아이콘은 후속 대상이다. 원본 SVG 확보 여부와 신호 세기 표시 기준을 확인한 뒤 적용한다.

### 3. Wi-Fi 비밀번호 화면의 필드와 상단 버튼

- 원본 `982:3174`: 비밀번호 입력창의 옅은 테두리, 비활성 회색 눈 아이콘, 우측 상단X.
- 앱 `_credentials`: 외곽 테두리 없음, 눈 아이콘은 진한 `textPrimary`; 상단은 공통 좌측 뒤로 가기다.
- 눈 아이콘의 보이기/숨기기 의미는 유지하며 색을 맞추고, 닫기 시 중단·이탈 처리와 현재 뒤로 가기의 차이를 확인해야 한다.

## 추가 확인이 필요한 항목

- 종 선택 팝업: 원본 `1043:3143`은 구분선이 있는 흰 목록. 앱은 기본 `DropdownButtonFormField`다. ‘당장은 크레스티드 게코만’이라는 사용자 승인은 유지하며 **펼친 상태의** 여백·반경·그림자를 별도 검수해야 한다. 원본의 여러 종을 그대로 추가하지 않는다.
- 빈 Wi-Fi 비밀번호의 연결 버튼: 원본은 비활성, 앱은 busy 조건으로만 비활성화한다. 개방형AP 지원과 수동 SSID 흐름을 함께 확인해야 하므로 단순 공백 차단을 넣지 않았다.
- 드롭다운 그림자 정확 수치는 이전 검수에서 보류된 항목이다.

## 검수 범위와 검증

- 최신 원본 Home·Camera·MyCre·개체 폼·종 선택·개체 선택·기기 선택·그룹 설정·Wi-Fi9개 화면을 직접 export하여 확인했다.
- Home·Camera·MyCre는 기존 시뮬레이터 캡처와 비교했다. 영상 비연결, 가상 측정값, ‘업데이트 없음’, 평균 미제공 등 승인된 표시 차이는 새 오류로 분류하지 않았다. 이번에 모든 팝업·모든 상태를 전수 검증했다는 의미는 아니다.
- 관련 테스트 **21통과**: 작은 화면/글자1.7배의 연결 단계, 기존 그룹 선택·취소 동작, 시각 캡처 포함.
- 정적 분석 오류0·경고0, 기존 info6.
- `app/` 이미지는 **Flutter 위젯 렌더링 검수**다. 이번 턴에 시뮬레이터 새 빌드를 설치하거나 서버/DB를 변경하지 않았다.
- 신규 기능/계약이 필요한 추가 발견은 위에 기록했으며, 이번 커밋의 앱 변경은 승인된 체크박스 범위다.
