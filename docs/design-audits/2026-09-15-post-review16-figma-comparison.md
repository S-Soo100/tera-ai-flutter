### 07 개체 수정

입력칸 테두리·체크 원본 비율·검색/달력 회색 반영 확인. 사진 추가 아이콘은 원본보다 진하게 보이며 textTertiary로 일괄 tint 중. 성별 선택 구분선은 원본 노드에 있으나 현재 Container에 없음. 이번 캡처 하단 밖의 입양일·체중·그룹·메모·저장 버튼은 판정 보류.

### 08 카메라

카드 레이아웃과 승인 업데이트 접두사/없음 반영 확인. 공통 헤더 드롭다운 V자→채운 삼각형 차이. 라이브 실패·회색 썸네일은 검수 데이터 연결 상태로 시각 일치 판정 제외.

## 추가 검토 후보와 원인

1. **03 그룹 구성원 아이콘 복원**: Figma `765:7549`의 36px 아이콘 3개+24px 체크 구조 중 현재 체크만 구현.
2. **03 그룹 추가 카드 복원**: Figma `765:7560`은 369×52, 회색 배경, 24px plus, 좌측 정렬. 현재 `TextButton` 중앙 텍스트.
3. **03 여백·행·하단 버튼 치수**: 원본 기기행 x24/y122, 그룹카드 y186/h78; 현재 코드 x12/y130, 카드 y190/h약82. 원본 하단 버튼군은 56+56, 현재 제외 TextButton에 별도 세로 padding16이 적용돼 높이 차이.
4. **05 Y축 잘림**: `_axisOverlay` 내부 Stack의 첫 라벨을 음수 top으로 배치하고 기본 clip이 적용됨. 스크린샷에서 27°/80% 윗부분 잘림 확인.
5. **05 세로 격자**: 원본 `765:2557`에 세로 격자 및 시간 행 구분 구조가 있으나 현재 `_DayPlotPainter`는 가로선만 그림(스크러버 제외).
6. **05 분무 기록 색**: 원본 PNG 파랑. runtime `3636/humidity_high.svg`는 원 배경 `#2E408C`이고 `metric`으로 직접 표시해 `glass.deviceMist=VivaColors.blue`를 사용하지 않음. 기존 토큰을 활용하는 방식으로 검토.
7. **06·08 공통 드롭다운**: Figma `keyboard_arrow_down`의 V자 대신 `redesign_v2/arrow_drop_down` 채운 삼각형 사용. V자 원본 `assets/icons/dropdown.svg`는 이미 있음.
8. **07 사진 아이콘·성별 구분선**: 사진 아이콘을 textTertiary로 tint해 원본보다 진해짐. 성별 비선택 버튼의 원본 stroke `#E3E3E3`가 현재 Container에 없음. 현재 암컷 선택 캡처에서 비선택 버튼 간 경계는 직접 인접하지 않아, 미구분 선택 상태 재촬영이 필요.
9. **02 전원 스위치 외형**: 원본 중앙 세로선, 현재 흰 선택 캡슐. 기능은 승인된 항상 ON 유지하며 외형만 별도 검토.

## 데이터·승인에 따른 차이

- 그룹명 우선 표시와 첫 번호 1은 최신 사용자 확정이므로 원본 예시 이름을 그대로 복사하지 않음.
- 온습도·활동 그래프 수치/형상/날짜는 자연스러운 가상 데이터로 바뀐 결과. Figma 예시 값을 맞추는 것은 요구사항이 아님.
- MyCre 평균 `--`와 관측 미확인 설명은 데이터 계약 관련 표시. 설명으로 주간 섹션이 내려가지만 평균을 지어내거나 안내를 임의로 제거하지 않음.
- 하이라이트 `업데이트 없음`, 북마크 `업데이트 오늘/어제/N일 전`은 승인한 문구.
- 카메라 실패 화면·회색 썸네일은 가상 검수 진입점의 연결 상태이며 정상 라이브 화면 일치 여부는 이 캡처로 검증하지 못함.

이번 요청에서는 비교 및 프로젝트 모델 규칙 문서만 변경했다. 위 추가 후보는 아직 구현하지 않았다.
