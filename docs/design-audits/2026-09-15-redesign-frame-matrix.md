## 이번 구현

- 라이트 팔레트 wallpaper / overlayStrong / surfaceHeader를 흰색으로 변경.
- 기본 AppBar의 scrolledUnderElevation을 0으로 고정. 카드 #F4F4F4 유지.
- 원본 해시 74개 확인 후 SVG 70개의 runtime 사본을 생성.
- 불투명 alpha mask의 rect만 흰색으로 정규화. 글리프와 원형 배경 색은 보존.
- PNG 원본 4개를 번들에 등록하고 ExactAssetImage(scale: 3)로 연결.
- 카메라 진입 카드의 SVG 2개를 신규 runtime 경로로 연결하고 현재 Figma의
  `765:4499` / `765:4507` PNG export와 도형을 비교.

재생성: `python3 tools/prepare_redesign_assets.py`.
대응표: [asset map](2026-09-15-redesign-asset-map.json).
SVG mask id에 들어 있는 과거 export node 번호는 현재 페이지 node ID로
사용하지 않는다. 이번 조회에서 해당 과거 번호는 유효하지 않았다.
