# 검수 17 — 그룹 이름 중복 오류

상태: 차이 발견. 이번 턴 앱 코드 수정 없음. 16번 기본 배치는 사용자 승인.

원본Figma axfr9s1n 987:5869 신규 조회/export와393×852 /SafeArea62·34 제품 위젯을 비교했다. 이번 앱 이미지는 실제 시뮬레이터가 아닌 위젯 캡처다. 시뮬레이터 CUA 입력은 setValue 미반영/클립보드 읽기 시간초과로 재현이 확인되지 않아, tester.enterText로 기존 이름 입력→포커스 해제→버튼 탭해 실제 검증 로직의 오류 상태를 캡처했다.

기본 헤딩/안내/입력창 위치, 버튼x12,y696,369×56 및 글자18pt/600/줄높이28은 유지된다. 앱 TextFormField 측정높이85는65pt 입력상자+오류영역 포함값이므로 입력상자 자체가20pt 늘어났다는 뜻이 아니다.

제품은 이름 변경 시 오류 상태를 지우고 버튼 탭 때 검사한다. 원본 오류 상태의 비활성 버튼을 구현하려면 오류 발생 후 다시 수정했을 때 재검증/활성 복구 흐름을 함께 확인해야 한다. 새 로직은 이번 턴 구현하지 않았다.
