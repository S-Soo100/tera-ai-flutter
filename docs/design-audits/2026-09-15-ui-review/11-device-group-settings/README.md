# 검수 15 — 기기의 그룹 설정

상태: 사용자 검수 대기. 이번 턴 앱 수정 없음.

Figma axfr9s1n 994:13167 신규 export(393×852), 0.107.20+231 실제 iPhone17 QA 시뮬레이터 캡처(402×874pt). 카메라 상세에서 그룹 설정으로 진입했다.

검수 범위: 상단 기기 아이콘·이름·ID, 그룹 번호/이름과 구성원 아이콘·체크박스, 그룹 추가, 완료/그룹에서 제외 배치. 전체 수치 정밀 재측정과 그룹 변경·제외 동작 검수는 아직 별도다.

원본은 카메라 아이콘만 진회색이고 앱은 세 아이콘 모두 진회색이다. 현재 앱 코드는 해당 그룹에 그 종류의 구성원이 있으면 진회색, 없으면 회색으로 표시한다. QA 그룹에는 사육장·카메라·개체가 모두 있어 세 아이콘이 진하게 표시된다. 이 상태 차이만으로 색상 구현 오류로 단정하지 않는다. 아이콘 순서는 사육장→카메라→개체로 고정된다. 원본 실제 구성원 데이터는 확인할 수 없다.

그룹 선택 체크는 check_box_300, 미선택은 check_box_outline_blank_400 사용. 하단 완료/그룹에서 제외는 목록 밖 고정 영역이며 긴 목록에서 Figma가 요구하는 겹침 여부는 이 정지 화면만으로 검증 완료 처리하지 않는다.

이름·ID·그룹명은 가상 데이터. 저장·그룹 제외·추가를 실행하지 않았다. 현재 화면만 확인했다.
