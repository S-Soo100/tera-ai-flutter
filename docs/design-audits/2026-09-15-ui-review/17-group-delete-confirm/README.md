## 수정 제안

표시 문구를 Figma의 ‘이 그룹을 삭제하시겠습니까?’로 맞춘다. 추가 설명을 없애면 현재 반응형 레이아웃에서 본문28pt·팝업144pt로 줄어든다. 기존에 확정한 기능(그룹만 삭제, 구성원은 그룹 없음으로 이동)은 유지한다.

전체 화면 딤·그림자의 정밀 수치는 이번 일치 판정에 포함하지 않았다. Figma는 모달만 그림자 포함385×184 export이며, 앱은393×852 전체화면이다. 비교 페이지의 앱 확대는 CSS 자르기다. 이번 단일 이름/기본 글자 배율 조건의 측정이며 큰 글자 설정은 별도다.

## 수정 및 확정

- 체험 흐름: 그룹 상세에서 삭제 누름 → ‘이 그룹을 삭제하시겠습니까?’ 한 줄과 취소/삭제 버튼 표시 → 취소 시 원래 상세로 복귀. 기존 그룹만 삭제하고 구성원은 유지하는 기능은 변경 없음.
- 문구를 원본으로 변경. 팝업 x24/y368/345×144, 본문 y392/높이28 확인.
- 본문 TextAlign.center 및 실제 글자 영역의 중앙 검증. 본문 중심x196.5, 화면/팝업 중심x196.5로 일치. 버튼 글자도 TextAlign.center.
- 짧은 Text 위젯의 렌더 박스는 글자 너비199.05로 줄어들지만 중앙 정렬은 유지된다. Figma의297pt 전체 텍스트 프레임과 박스 폭이 같아야 한다고 간주하지 않았다.
- 화면 가로393/SafeArea 상단62·하단34 기준. 팝업은 SafeArea 안의 세로 중앙y440에 배치된다. Figma가 독립 모달이므로 전체 화면 세로 좌표 일치는 별도 판정하지 않았다.
- 그룹 컨트롤러 회귀3개, 캡처·글자 중심·사육장/카메라 취소 확인1개 통과. 삭제/서버 쓰기는 수행하지 않았다.
- 임시 측정 테스트를 실제 글자 박스의 중심 기준으로 정정하고 통과 후 제거했다.
