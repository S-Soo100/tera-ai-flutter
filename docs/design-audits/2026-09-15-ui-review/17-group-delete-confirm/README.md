# 검수 21 — 그룹 삭제 확인창

상태: 원본 비교·수치 측정 완료. 문구 변경 제안 확인 대기. 삭제 문구는 아직 수정하지 않았다.

## 수정 제안

표시 문구를 Figma의 ‘이 그룹을 삭제하시겠습니까?’로 맞춘다. 추가 설명을 없애면 현재 반응형 레이아웃에서 본문28pt·팝업144pt로 줄어든다. 기존에 확정한 기능(그룹만 삭제, 구성원은 그룹 없음으로 이동)은 유지한다.

전체 화면 딤·그림자의 정밀 수치는 이번 일치 판정에 포함하지 않았다. Figma는 모달만 그림자 포함385×184 export이며, 앱은393×852 전체화면이다. 비교 페이지의 앱 확대는 CSS 자르기다. 이번 단일 이름/기본 글자 배율 조건의 측정이며 큰 글자 설정은 별도다.
