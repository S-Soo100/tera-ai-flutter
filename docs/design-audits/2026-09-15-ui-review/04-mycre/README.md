## 비교 사항

- 개체 카드·성별 배지·일간 요약·막대 그래프의 기본 구성을 비교한다. 그룹명/개체명/날짜는 QA 데이터다.
- 그래프는 야간 활동이 많은 로컬 가상 데이터이며 실제 개체 측정값이 아니다.
- 일간 눈금은 원본 샘플의 210 대신 확정 집계 계약인 시간당 최대 60분을 적용한다. 최고 막대는 빨강, 일반 막대는 회색이다.
- 과거 날짜를 보고 있어 오른쪽 다음 날짜 화살표가 표시된다.
- 현재 QA 데이터는 관측 완료를 확인할 수 없는 상태여서 평균이 --이고 그래프 아래 안내문이 표시된다. 운영 서버 전체가 미지원이라는 뜻으로 판단하지 않는다.
- 원본에 없는 평균 안내문이 세로 공간을 차지하여 주간 요약이 첫 화면 하단에 걸린다. 이 상태의 안내문 배치와 밀림을 사용자와 확정해야 한다. Figma와 완전히 동일하다고 판정하지 않는다.
- 하단 가상 데이터 안내는 QA 전용이다. 화면 하단의 표시 공간에도 영향을 주므로 일반 앱과 구분한다.

이번 확인에서는 06을 자동 승인하지 않는다. 평균 안내문 유지/배치 조정 의견을 먼저 확인하고 주간 그래프는 별도 검수한다.
