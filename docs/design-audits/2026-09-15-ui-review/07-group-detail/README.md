# 검수 11 — 그룹 상세

상태: **11 그룹 상세 기본 배치 확정**.

Figma axfr9s1n의 그룹 상세 990:6321을 새로 내보냈다. 이 프레임에는 이 그룹 삭제 버튼이 있다. 같은 문서의 1063:7025는 삭제 버튼이 없는 다른 프레임이므로 이번 비교에는 쓰지 않았다.

실제 시뮬레이터: 2026-09-16 00:51 기존 설치된 QA 앱에서 그룹 카드 진입 후 신규 캡처. 이번 턴에 앱을 새 빌드/설치한 것은 아니며 최근 MyCre 변경은 이 기기 관리 화면을 변경하지 않았다. 원본 393×852, 앱 402×874pt로 표시한다. 그룹/기기/개체 이름, 기기 ID, ON/OFF는 가상 데이터 차이다. 하단 가상 데이터 안내는 QA 전용이다.

확인 범위: 그룹 이름 입력칸·글자수, 이 그룹의 목록, 사육장→카메라→개체 행/화살표/구분선/모서리, 추가·변경, 완료와 이 그룹 삭제 버튼 기본 배치. 실제 저장·구성원 변경·삭제 확인 팝업은 별도 검수다. 기본 구성은 원본에 대응하며 앱 코드 수정 없음.
