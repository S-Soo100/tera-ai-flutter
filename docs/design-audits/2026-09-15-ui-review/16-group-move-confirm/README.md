## 원인 및 수정 제안

공통 ManagementButton은 일반 페이지56pt 버튼을 기준으로 상하14pt 패딩과18pt 글자를 쓴다. 이를 다이얼로그의44pt 영역에 넣으면서 글자 공간이16pt(44−28)로 줄었다.

1. 다이얼로그 버튼 전용 크기 지정: 높이44, 글자16/600/줄높이28, 상하8pt 패딩. 일반 페이지56pt 버튼은 기존대로 유지.
2. 다이얼로그 외곽 radius16→12.
3. ‘선택한 관찰 카메라은’의 조사 결합 오류 수정. 원본 문장 구조를 유지하면서 실제 이름에 맞게 은/는 선택. 앞서 기록한 ‘새 그룹 그룹으로’의 중복도 같은 확인 문구 경로에서 정리할 것을 제안.

본문의 이름이 길면 줄바꿈과 높이가 달라질 수 있다. 원본 샘플과 문장 줄바꿈이 다른 것은 동적 이름 길이 차이도 있으므로 임의 축소하지 않는다. 버튼 글자 잘림은 이름 길이와 무관한 구현 문제다.

## 검증 범위

제품 위젯 측정·캡처 및 취소 동작 확인. Figma는 독립된 모달 노드로 export되어 그림자 포함385×240, 앱은393×852 전체화면이다. 비교 페이지의 확대는 원본 이미지에 CSS 자르기만 적용한다. 전체 앱 캡처도 제공한다. 화면 전체 딤 색상과 Figma 그림자 수치는 이번 일치 판정에 포함하지 않았다. 실제 서버 생성/기기 이동 없음.
