## 검증 범위

- 자동 위젯 테스트 통과, 실제 구성원 선택→최종 확인 진입 및 레이아웃 예외 없음 확인.

- 아이콘의 프레임 및 중심 배치를 측정했다. 내부 SVG 픽셀 경계 전체의 완전 일치까지 판정한 것은 아니다.
- 앱 이미지는 시뮬레이터 스크린샷이 아닌 제품 위젯 캡처다. 상태바는 포함되지 않는다.
- 그룹 이름·상태·ID 차이를 제외해도 추가·변경 정렬 차이가 남으므로 전체 일치로 승인 처리하지 않았다.
