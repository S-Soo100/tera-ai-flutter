텍스트 가로 폭은 글자 내용과 렌더링 경계 때문에 약1px 차이가 있어 전체 픽셀 완전 일치로 주장하지 않는다. 원본 이름은 예시, 실제 QA는 기존 사육 환경1이 있어 사육 환경2로 시작한다. 입력 포커스/커서는 원본 예시와 다르다. 버튼은 스크롤 밖 고정 영역에 있으며 기본 상태에서 같은 위치다. 키보드 표시, 중복 이름 오류, 긴 입력 시 배치/활성 정책은 별도 검수 대상이다.

QA에서 카메라 상세→그룹 설정→그룹 추가→변경을 통해 진입할 때 No ProviderScope found가 발생했다. QA main은 각 GoRoute 안에만 ProviderScope가 있어 Navigator.push된 그룹 화면에 전달되지 않았다. 실제 lib/main.dart에는 앱 위의 ProviderScope가 있다. QA도 앱 최상위에 가상 override scope를 추가하고 다시 빌드했다. 같은 경로를 재실행해 그룹 이름 입력 정상 진입을 확인했다. 제품 코드는 변경하지 않았고 서버 이동/저장은 실행하지 않았다.
