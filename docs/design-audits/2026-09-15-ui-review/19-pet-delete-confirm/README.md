## 원인과 수정 제안

이 화면은 PetManagementScreen._delete의 기본 AlertDialog를 사용해 앞서 수정한 managementConfirm 디자인이 적용되지 않는다.

- 20~22에서 검증한 공통 확인창 구조 적용: 흰 바탕345pt·반경12·본문18/500/줄높이28/중앙 정렬·동일 너비 검정/빨강 버튼.
- 실제 개체 이름을 넣고 한국어 조사를 맞춰 ‘크랑이를 삭제하시겠습니까?’ 표시.
- 두 번째 줄은 원본 ‘크레 활동 데이터, 그래프도 삭제됩니다.’ 유지. 버튼은 취소/삭제로 표시.
- 기존 onDelete 콜백, 취소 시 무동작, 진행 중 중복 삭제 차단은 유지. 이 UI 변경으로 저장소나 실제 삭제 범위를 변경하지 않는다.
- 긴 이름은 줄바꿈에 맞춰 팝업 높이를 늘리되 글자 잘림을 피한다. 원본 크기172pt는 짧은 이름의 두 줄 조건에서 검증한다.

## 검증

기존 /my-pets/:petId의 PetDetailScreen에는 별도 구형 삭제 확인창도 존재한다. 이 경로는 이번 캡처가 아니며 이후 구형 상세 진입 경로 검수에서 별도로 확인해야 한다.
