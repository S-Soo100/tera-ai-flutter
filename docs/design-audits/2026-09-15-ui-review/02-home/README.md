# 검수 04 — 홈 본문 기본 배치

상태: **04 홈 기본 배치 및 영상 표시 비율 승인**.

세 탭 드롭다운 기본 배치(01~03)는 승인됨. 공통 그림자 수치 대조는 보류 유지.

04는 앞선 두 차례 비교에서 저장한 실제 시뮬레이터 화면을 재사용한다. 이번 턴에 새로 촬영한 화면이 아니다. 원본은 axfr9s1n에서 확보한 Home 1081:4308. 앱 화면은 402pt, 원본은 393pt 논리 폭으로 나란히 표시한다.

이번 확인 범위: 영상 영역의 크기·모서리·바깥 여백, 온습도 요약 카드, 환기팬/분무/냉각팬/LED 카드의 배치·간격·색상, 기기 설정 제목과 일정 설정 행. 육안 비교에서 이 범위에 추가 수정 제안은 없음. 실제 데이터·기기 이름·연결 실패 문구는 레이아웃 차이로 판단하지 않는다.

영상은 의도적인 검수용 연결 실패 상태이며 측정값은 로컬 가상 데이터다. 정상 영상 재생 및 오류 UI, 스크롤 아래 영역·Android는 별도 검수 대상이고 이번 승인에 포함하지 않는다. 앱 코드는 변경하지 않았다.

## 사용자 확정

영상틀 Figma 369×271px, 앱 홈/카메라 공통 369/271 비율을 확인한 뒤 사용자가 ‘오케이 다음’으로 진행 승인. 기본 배치와 영상틀 비율을 확정한다. 정상 영상 재생·오류 UI·스크롤 아래·Android 검수는 별도 유지.
