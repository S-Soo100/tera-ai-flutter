## 검증 범위

- 위젯 캡처·측정 테스트1개 통과, 레이아웃 예외 없음. 임시 테스트 제거.

- ON/OFF는 기존 승인된 ON 고정 표시 정책이다. 기기명 첫 번호는 승인된 새 기본 이름 규칙을 따른다. 원본 예시의 OFF·번호 없는 이름과 분리해 판단한다.
