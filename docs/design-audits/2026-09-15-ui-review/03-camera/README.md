# 검수 05 — 카메라 본문 기본 배치

상태: **사용자 확인 대기**.

01~03 드롭다운 기본 배치, 04 홈 기본 배치 및 영상틀 비율 승인. 드롭다운 그림자 수치 대조는 보류 유지.

Figma 원본: axfr9s1n에서 저장한 Camera 1081:4417. 앱: 2026-09-15 23:43 iPhone 17 시뮬레이터에서 새로 촬영한 QA 화면. 원본 393pt와 앱 402pt 폭으로 비교한다.

확인 범위: 하이라이트·북마크 영상 카드의 아이콘/색상/간격, 업데이트 문구, 기간 설정 버튼, 시간·날짜 정렬, 3열 썸네일과 북마크 표시. 영상틀은 홈과 같은 369/271 비율이다. 육안 비교에서 주요 배치가 대응하며 이번 단계에서 확정할 수정 제안은 없다.

그룹 이름 표시는 후속 승인 사항이며 Figma 캡처의 개별 카메라 이름과 달라도 의도된 동작이다. ‘업데이트 없음’은 앞서 승인한 데이터 없는 경우의 문구이고 ‘업데이트 오늘’은 로컬 QA 날짜에 따른 표시다.

영상 연결 실패와 회색 썸네일은 로컬 QA 데이터 상태다. 실제 재생·이미지 채움/잘림·네트워크 오류 UI는 이 캡처로 검증하지 않는다. 하단 가상 데이터 안내도 QA 전용이다. 기간 선택 및 카드 진입 후 화면, 전체 스크롤, Android는 별도 검수한다. 앱 코드는 변경하지 않았다.
