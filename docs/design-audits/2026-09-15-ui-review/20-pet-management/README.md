1. 이 목록 화면의 헤더를 우측 닫기로 맞춘다. 다른 입력 페이지의 뒤로가기를 일괄 변경하지 않는다.
2. 기본 이미지는 이미 확보된 favicon_viva_50x3.png를80pt 프레임에 맞게 표시하고 사진 모서리4pt 적용. 새 에셋을 받을 필요는 없다.
3. 이름 굵기700 및 색상, 흰 성별 배지, 모프/체중 배치·자간을 원본에 맞춘다. 정수 체중은21g로 표시한다. 성별은 기존 ColorSystem을 활용한다.

10자 ‘크랑이네작은도마뱀왕’을 새로 캡처했다. 사진 precache 후 이름 전체가 보이고 RenderParagraph.didExceedMaxLines=false, 레이아웃 예외 없음이다. 이전 모달 배경 캡처에서 의심된 이름 앞부분 잘림은 이번에 재현되지 않았으므로 확정 버그로 분류하지 않는다. 배지·굵기 변경 후 다시 검증할 것.
