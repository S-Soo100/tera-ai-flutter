# 이후 검수 예상 범위 — 2026-09-16

25번 개체 입력 초기 화면 수정 이후 남은 안건의 작업 추정이다. 확정된 프레임 총수가 아니며, 사용자와의 검수에서 공통 레이아웃을 묶거나 오류/상태 화면을 분리하면 달라진다. 이전 구현·자체 QA를 이번 사용자별 최종 승인으로 대체하지 않는다.

| 묶음 | 예상 검수 안건 | 범위 |
|---|---:|---|
| 개체 입력 세부 |5~6|완성/이름오류,종 선택,모프 검색·선택·결과없음,날짜/사진/그룹선택,저장·이탈·등록완료|
| 사육장·카메라 연결 |6~7|검색/검색실패,기기선택,네트워크목록/실패,비밀번호/오류,연결중,완료·복수등록|
| 빈 상태 |2~3|홈·카메라·MyCre 및 기기없는 상태|
| 온습도 상세 |2|일간·주간과제어기록|
| 홈 제어·설정 |3~4|팬시간,분무/냉각/밝기,일정,LCD화면설정|
| 영상 상세 |2~3|하이라이트/북마크목록,메모·삭제,플레이어/기간선택|
| 합계 |20~25|임시 추정치 |

지속 확인: 드롭다운 그림자,구형 개체상세 진입·삭제UI,원본에서 확인되지 않은 버튼고정 설정. 새로 발견되는 독립 차이는 위 예상에 추가될 수 있다.

전체 UI검수 이후 활동 평균의 표시 조건/서버 관측완료 연동 안건을 사용자에게 반드시 다시 제시한다(별도 기능 논의).
