## 이후 모든 페이지의 필수 수치·버튼 확인 항목

같은 논리 화면 크기와 SafeArea에서 간격·패딩, 폰트 크기·굵기·줄높이·자간, ColorSystem 실제 색상, 아이콘 프레임과 내부 그림 크기·정렬, 버튼 위치·활성 조건·터치 영역을 필수로 대조하고 측정값과 캡처를 남긴다.

Figma별 스크롤 내부 / 별도 영역 고정 / 콘텐츠 위 플로팅을 구분한다. 활성·비활성 조건, 버튼 뒤 콘텐츠 노출, 하단·좌우 여백, SafeArea, 마지막 항목을 가리지 않고 조작할 수 있는지를 실제 스크롤로 검수한다. 이미 승인한 화면도 버튼 구조가 확인되지 않았다면 이 항목의 검증 완료로 간주하지 않는다.

## 전체 UI 검수 종료 후 반드시 다시 논의

**활동 평균 표시 조건과 서버 연동 보완** — 사용자 요청: “검수 완료하고 다시 주제를 꺼내줘”. 전체 UI 검수 종료 보고 전에 이 안건을 다시 제시한다. 지금은 결정을 미루고 UI 검수를 이어간다.

현재 주간 평균은 관측 완료된 날짜만 대상으로 계산한다. QA 데이터 및 현재 HTTP 저장소가 coverage를 채우지 않아 연결된 카메라의 평균이 --다. 일평균도 동일한 완료일 조건을 사용한다. 완료일 판정에 필요한 정보/서버 담당/앱 연동 또는 평균 정의 변경 여부를 검수 후 논의한다. 평균 계산 정책 변경이나 서버 작업은 아직 승인하지 않았다. 서버의 최신 배포 상태는 재논의 시 다시 확인한다.


**현재 카메라 기준 그래프 — 2026-09-16 확정 및 구현 완료**: MyCre는 현재 그룹 카메라의 조회 가능 기록을 사용한다. 개체 등록일/연결일/카메라 등록일로 기간을 자르지 않고, A→B 교체 시 선택한 날짜를 유지하면서 B로 전환한다. A의 과거 기록은 이어 붙이지 않는다. 이력 DB는 변경하지 않는다. 0.107.17+228. MyCre/개체 테스트 59개 통과·캡처 전용 1개 skip, 분석 오류 0·경고 0(기존 info 6개). 서버 실데이터 권한/보존 범위는 별도 검증 대상이다. 평균 표시 문제는 전체 UI 검수 후 다시 제시한다.
