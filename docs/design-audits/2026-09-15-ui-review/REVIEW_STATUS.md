## 전체 UI 검수 종료 후 반드시 다시 논의

**활동 평균 표시 조건과 서버 연동 보완** — 사용자 요청: “검수 완료하고 다시 주제를 꺼내줘”. 전체 UI 검수 종료 보고 전에 이 안건을 다시 제시한다. 지금은 결정을 미루고 UI 검수를 이어간다.

현재 주간 평균은 관측 완료된 날짜만 대상으로 계산한다. QA 데이터 및 현재 HTTP 저장소가 coverage를 채우지 않아 연결된 카메라의 평균이 --다. 일평균도 동일한 완료일 조건을 사용한다. 완료일 판정에 필요한 정보/서버 담당/앱 연동 또는 평균 정의 변경 여부를 검수 후 논의한다. 평균 계산 정책 변경이나 서버 작업은 아직 승인하지 않았다. 서버의 최신 배포 상태는 재논의 시 다시 확인한다.
