Figma는 사육장·카메라·개체의 목록마다 연회색 배경과 둥근 외곽을 적용한다. 현재 구성원 선택 단계는 ManagementItemRow를 직접 나열하고 있어 흰 배경/구분선만 보인다. 그룹 상세(review 단계)는 이미 Material overlay/radius12로 묶지만 members 단계에는 적용되지 않았다. 종류별 목록에도 기존 팔레트 배경과 radius12를 적용하는 수정을 제안한다. 사용자 확정 전에는 수정하지 않았다.

원본은 구성원이 여러 명이고 모두 미선택된 예시, QA는 종류별 1개가 기존 그룹 구성원으로 선택된 상태다. 항목 수·이름·상태·체크 유무와 하단 버튼 활성 여부는 데이터/상태 차이로 구분한다. 선택 해제 및 실제 구성원 이동·저장은 아직 검수하지 않았다. 앱 코드는 이번 턴 변경하지 않았다.
