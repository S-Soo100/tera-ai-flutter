## 차이와 처리

1. **[수정] 사진 없이 보호기가 꺼져 있을 때 설정 화면 줄 값** — 앱 "사진 없음" / Figma "꺼짐". 기획 §11-4를 "켜져 있을 때만 '사진 없음'"으로 고치고 코드 반영.
2. **[수정] 꺼짐 시간 화면이 기기 값을 불러오기 전에 열리면 처음 값이 기본값(20:00~08:00)으로 굳음** — 캡처에서 서버 18:00이 20:00으로 보여 발견. 값이 도착했을 때 손대지 않은 초안이면 다시 잡도록 수정 + 회귀 테스트. (설정 화면을 거치는 보통 흐름에선 이미 불러와 있어 드묾)
3. **[기록, 수정 안 함] 꺼짐 시간 종료 블록 2px** — Figma는 시작 블록에서 제목→화살표 간격 3, 종료 블록에서 5로 서로 다르다(원본 내부 불일치). 앱은 두 블록 모두 3. 확인 필요 시 디자이너에게.
4. **[결정에 따른 차이] 보호 사진 화면 — 사진 없을 때 보호기 스위치 흐림 + "사진을 먼저 추가해 주세요" 한 줄** — D9(사진 없으면 켜기 막기). Figma엔 흐림·안내가 없다.
5. **[결정에 따른 차이] 보호기 줄 제목 "보호기 · 꺼짐"** — Figma 사진 없음 프레임은 스위치가 꺼져 있는데 제목이 "보호기 · 켜짐"(정적 문구로 보임). 앱은 "화면 전원 · 켜짐|꺼짐"과 같은 규칙으로 상태를 따른다.
6. **[캡처 한계] 스테퍼 −/+ 가 네모로 보임** — 테스트 환경에 Material 아이콘 글꼴이 없어서다. 같은 `VivaStepper`를 쓰는 온습도 설정 화면은 기기에서 정상.
7. **[캡처 한계] 사진 있음 캡처에 사진·메뉴 없음** — 미리보기는 네트워크 이미지라 테스트에서 안 그려지고, 메뉴는 별도 Overlay라 캡처 경계 밖이다. 메뉴 위치는 위젯 테스트가 Figma 좌표로 고정. 사진 있음 프레임의 완료 활성은 Figma가 '바꾼 뒤' 상태라 다르다(앱은 바뀐 게 없으면 비활성 — 기획 §2-9).
