## 💡 직관 질문 답변
- **빼도 되는 것:** 예약 경계 타이머(뺐음). 자르기 화면은 확정 결정이지만 마지막 단계로 미뤄 서버 미리보기를 안전망으로 둔다.
- **최대 리스크:** 서버 미배포·실기 미검증 상태에서 사진 실패 시 '기기엔 사진 없음 / 서버 key는 그대로'가 생겨 앱이 기기와 다른 화면을 자신 있게 보여주는 것.
- **먼저 만들 것:** 온라인 `lcd_saver` 기기 1대 스파이크 — PUT power·quiet, POST image(성공 1·기기 끈 상태 실패 1), 사진 수신 중 PUT saver. `commands` 결과 시점, devices 실시간 새 컬럼과 ok 뒤 지연, 실패 뒤 `lcd_image_key` 실측.
