## 사용자 체험 흐름

- 그룹: [화면] 연회색 카드에 세 구성원과 화살표 → [조작] 행 탭 → [반응] 해당 기기 상세 또는 개체 수정 → [감정] 소속과 이동 대상을 바로 이해. 뒤로 돌아오면 그룹 편집 내용 유지.
- 그룹 설정: [화면] 기기 상세의 그룹 설정 → [조작] 설정 화면에서 그룹 제외 선택 → [반응] 확인, 취소 시 그대로·확정 시 소속만 해제 → [감정] 삭제와 혼동하지 않음.
- 그래프: [화면] 기존 실제 데이터와 눈금에 Figma 색·굵기·점선·막대 라운드 → [조작] 기존 기간/스크럽 → [반응] 기존 집계 유지 → [감정] 지표 구분과 시간 읽기가 쉬움.
- 개체 폼: [화면] 경계가 보이는 입력칸, 원본 비율 체크·회색 검색/달력 → [조작] 기존 입력/선택 → [반응] 기존 저장/검증 흐름 유지.
- 카메라: [화면] 북마크는 업데이트 접두사+상대 날짜, 실제 공개 시각 미지원 하이라이트는 업데이트 없음 → [조작] 카드 탭 → [반응] 기존 목록 이동.

## 구현 결과

- 1·2: 그룹 목록을 연회색 둥근 카드로 묶고 기존 그룹의 세 종류 구성원 행에 상세/개체 수정 이동 연결.
- 7: 그룹 없음 안내는 Figma 64px 높이 카드로 표시.
- 11·12·15·16: Figma 상세 행 간격 24px, 그룹 설정 18px 화살표, 추가 온라인 문구 제거. 그룹 설정 페이지 안으로 제외 버튼 이동, 확인/취소와 기존 removeMember 유지.
- 3·4: 일간 그래프 색은 기존 tempAccent/humidAccent → VIVA mainLight/subLight. 기존 AppTheme 차트 별칭도 같은 토큰으로 정리. Figma 3배 PNG의 정상에 가까운 선 두께 11~12px를 확인해 4px로 적용.
- 5·6: 활동 막대 위 라운드, 일간 시간축 6시간 간격 세로 점선. 주간에 일간 분할선을 추가하지 않음.
- 8~10: 폼 기본 테두리, 24px 체크 배치 영역 안에 원본 15×11 비율 표시, 기존 deviceOff 회색 아이콘.
- 13·14: 북마크 상대 날짜에 업데이트 접두사. 밤 묶음 날짜를 공개 시각으로 취급하지 않고 업데이트 없음 표시. 실제 빈 상태/조회 실패 키는 유지.
