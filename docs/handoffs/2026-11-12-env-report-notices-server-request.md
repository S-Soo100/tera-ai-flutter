## 0. 앱에서 이미 한 것

- **주간 안내에 "안내" 칩**(0.177.3+512, main 병합): `notices` 항목마다 회색 "안내" 칩 + 서버 `title`·`body`를 그대로 그린다. 서버 변경은 필요 없다.
- 앱은 분석 문구를 만들지 않는다. 화면 문구는 모두 서버 `title`·`lines`·`body`다.

## 1. 요청 ① 일일 분석 — 데이터 수집 불안정 안내

**Figma `1736:5264`** (일일 카드, 지표 칩 "온도"):

| 칸 | Figma 문구 |
|---|---|
| 제목 | 데이터 수집이 원활하지 않았어요 |
| 설명 | 일일 분석을 위한 데이터가 충분하지 않아요. 전원과 Wi-Fi 연결 상태를 확인해 주세요 |

지금 일일 행에는 `notices`가 없다. 데이터가 모자란 날은 카드가 없거나 행이 없어서, 앱 화면에는 아무것도 나오지 않는다.

**제안(1안 — 앱 수정 없음):** 그 지표의 **`temp_card`/`humid_card` 자리에** 안내를 카드로 담아 주세요.

```json
"temp_card": {
  "element": "temp",
  "code": "ERR_DISCONNECT",
  "status": null,
  "title": "데이터 수집이 원활하지 않았어요",
  "lines": ["일일 분석을 위한 데이터가 충분하지 않아요. 전원과 Wi-Fi 연결 상태를 확인해 주세요"]
}
```

- 기존 카드와 같은 필드를 쓴다. `element`는 `"temp"`/`"humid"`다. 주간 `notices`의 `metric` 값인 `t_a`/`h_a`를 넣으면 앱이 카드를 버린다. `title`이 비어 있어도 버린다.

- 앱은 일일 카드를 지표 칩("온도" 빨강 / "습도" 남색) + 제목 + 설명 줄로 그린다. Figma 1736과 같은 모양이라 그대로 나온다.
- 일일 카드에는 상태 칩이 없으므로 `status`는 무엇이든 상관없다.
- 지표가 둘 다 모자라면 두 카드 모두 안내로 보내면 된다(구분선을 두고 두 줄로 그려진다).

확인할 것:
1. 데이터가 모자란 날에도 일일 **행이 만들어지나요?** 행이 없으면 앱은 그날 아무것도 그리지 않는다. 안내를 띄우려면 행이 필요하다.
2. 일일 "모자람"의 기준(누락률 몇 % 이상, 또는 유효 샘플 몇 개 미만)을 알려 주세요. 주간 `ERR_DISCONNECT`와 같은 기준이면 그렇다고만 적어 주세요.
3. 1안이 어렵고 일일 행에 `notices`를 따로 두고 싶다면 알려 주세요. 그러면 앱이 주간과 같은 방식으로 받도록 고친다.

## 2. 요청 ② "습기가 감지되지 않았어요" — 새 경우

**Figma:** 일일 `1736:5264` 둘째 줄(지표 칩 "습도"), 주간 습도 `1738:5288`("안내" 칩).

| 칸 | Figma 문구 |
|---|---|
| 제목 | 습기가 감지되지 않았어요 |
| 설명 | 분무를 잊지 않으셨는지 확인해 주세요 |

서버에도 앱에도 이 경우가 없다.

확인할 것:
1. **판정 조건**을 정해 주세요. 앱이 짐작하는 뜻은 "집계 구간에 습도가 올라간 일(분무·습기 사이클의 습한 쪽)이 한 번도 없었다"다. 실시간 카드의 습기 사이클·주간 "건기 도달" 계산과 같은 기준을 쓰면 될 것 같다. 수집 자체가 끊긴 경우(①)와는 구분해야 한다 — 데이터는 있는데 습도가 안 오른 경우다.
2. **코드 이름**을 정해 주세요(예: `ERR_NO_HUMID_RISE`). 앱은 모르는 코드여도 화면에 그린다.
3. **보내는 곳:**
   - 일일: ①과 같이 `humid_card` 자리.
   - 주간: `notices`(`metric: "h_a"`).
4. **주간에서 카드와 함께 오나요?** 지금 앱은 `ERR_NO_DATA`만 카드를 대신하고, 그 밖의 안내는 **카드 위에** 함께 그린다. "습기 미감지"가 습도 카드를 대신해야 한다면 알려 주세요(앱의 `replacesCard`에 코드를 더한다).

## 3. 요청 ③ 주간 안내 문구

Figma 주간 온도 안내(`1738:5281`)와 서버 `ERR_DISCONNECT` 문구가 다르다.

| | 제목 | 설명 |
|---|---|---|
| 서버 현재 | 주간 데이터 수집이 원활하지 않았어요 | 센서 전원과 Wi-Fi 연결 상태를 확인해 주세요 |
| Figma | 데이터 수집이 원활하지 않았어요 | 일일 분석을 위한 데이터가 충분하지 않아요. 전원과 Wi-Fi 연결 상태를 확인해 주세요 |

- Figma 주간 카드의 설명에 "**일일** 분석을 위한"이라고 적혀 있다. 일일 카드(`1736:5264`)를 복사하다 남은 것으로 보여 **디자이너에게 확인 중**이다. 확정되면 다시 알리겠다.
- 그 전까지는 서버 문구를 그대로 두세요. 문구를 바꿀 때는 기존 행 재생성 여부도 함께 알려 주세요(앱은 저장된 행의 문구를 그대로 보여 준다).
