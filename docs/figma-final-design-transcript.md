## 2. `앱 ASIS 0807` — 현재 앱 피드백 (원문 그대로)

### 2.1 메인 피드백 (`409:2910`)

**홈**
- 사육장의 온습도가 직관적으로 더 잘 보였으면 좋겠음
- 활동분석요약 좋음 → 언제 잔거 같고 언제 일어난 거 같은지를 그래프에 화살표로 시간 지점을 표기해주면 좋지 않을까 싶음
- 어젯밤 리포트가 바로 보이는건 어떨지?
- 어젯밤 리포트에 배변도 들어가면 좋을듯
- 리포트가 좀 휑함, 어젯밤 하이라이트 영상이 들어가면 좋을듯
- 다개체일 경우의 UX/UI 고민 필요
- 우측 상단 바이탈 모양의 버튼이 프로필 옆에 있는데 의미가 없으면 제외 필요

**크레캠**
- 연결 썸네일 — 연결 안 됐을 때의 이미지 필요
- 연결 됐을 때 라이브가 보이는건지? 아닌거 같아서 문의
- 클립 — 하이라이트 필요
- 분류의 경우 드롭다운이 아닌 슬라이드 버튼식이 낫지 않을지?
- 클립별로 행동 태그(이동, 탈피, 음수, 놀이 등)를 달아주면 좋을듯
- 캠을 보면서 IoT 기능을 조작할 수 있도록 버튼이 캠 아래 작게 있으면 좋을듯 (분무 on/off, 환기팬 on/off, LED on/off 등)

**사육장 — 온습도 추이**
- 24시간 온습도 추이에 시간이 언제인지 표기 필요
- 습도의 경우 분무 시점을 표기해줘야 할듯
- **적정 온도가 21~29도가 맞는지? 적정 습도가 60~80%가 맞는지 확인 필요**
- 7일, 30일은 어떻게 봐야할지 감이 안 옴
- 일자별로 최저/최고 온도를 세로막대그래프 형식으로 해야하진 않을지? 평균 온도로 해야할지? 30일이 필요한지?

**커뮤니티**
- 커뮤니티에 글쓰기 기능 추가 — 베타테스터들이 Q&A나 자유글 올릴 수 있도록
- 사육위키의 경우 디자인이 좀 필요할듯

**전체적 고민**
- 라인업이 나뉘었을 때 미사용 기능을 어떻게 처리할 것인지?
- 다수 제품 구매시의 컨트롤 어떻게 할 것인지? → 단, 이거는 3개 이하까지는 하나씩 제어해도 무방할 것으로 보이고, 4개 이상 사는 고객이 나왔을 때 고민해도 될 문제로 보임
- 캠은 24시간 라이브로 연결되지만, AI로 분석할 거는 시간 제한을 두는게 어떨지? 17시~07시 등 개체 활동시간을 제한시켜서 고객이 설정하는 식으로. 어차피 활동이 없으면 클립이 없기 때문

## 5. 대조 결과 — 코드/PRD와의 차이

> 여기부터는 전사가 아니라 **해석**이다.

### A. PRD와 Figma 피드백이 정면 충돌하는 것

| # | PRD | Figma 피드백 | 성격 |
|---|---|---|---|
| F1 | §3.3 서브탭 `[사육장 제어]` \| `[타임라인]` **전환식** — 한 번에 하나만 | "캠을 보면서 IoT 기능을 조작할 수 있도록 버튼이 캠 아래 작게 있으면 좋을듯" = **동시 표시** | 구조 충돌. 서브탭 구조 자체를 재검토해야 한다 |
| F2 | 어젯밤 리포트 = 마이크레 탭 (`/my-pets`) | "어젯밤 리포트가 바로 보이는건 어떨지?" / "리포트 누르지 않아도 보이게" = **홈 노출** | 배치 충돌. PRD Q6(마이크레 후순위)와도 얽힌다 |
| F3 | §3.5 타임라인 필터 = **칩 고정 노출** | "분류의 경우 드롭다운이 아닌 슬라이드 버튼식" | 피드백이 가리키는 "드롭다운"은 크레캠 화면(`/crecam`)의 옛 UI로 보인다. 홈 타임라인은 이미 칩이라 **이미 해소됐을 가능성** — 스크린샷 확인 필요 |

### B. 즉시 조치 — 보안

`409:2915`에 **테스트 계정 이메일과 비밀번호가 평문**으로 Figma에 적혀 있다. Figma 파일은 링크 공유되면 그대로 노출된다.
→ 해당 텍스트 노드를 지우고 계정 비밀번호를 교체할 것을 권한다. 이 저장소에는 값을 옮기지 않았다.

### C. 코드가 이미 만족하는 것

| 피드백 | 현재 구현 |

| 어젯밤 리포트에 **배변** 항목 | 미구현 |
| 어젯밤 리포트에 **하이라이트 영상** | 미구현 |

| AI 분석 **시간대 제한 설정** (17시~07시 등) | 미구현. 사용자 설정 항목 신설 필요 |
| 크레캠 **미연결 플레이스홀더 이미지** | PRD §3.2에 오프라인 레이어는 있으나 "연결 안 됐을 때 이미지"는 별건 |
| 다개체 UX (스위치 or 한번에 보이게) | 현재는 헤더 드롭다운 + 스와이프. 피드백은 **한눈에 보기**를 원함 |

### E. 통계 탭 — 스펙 공백이 부분적으로 메워졌다

`/stats`는 현재 19줄 빈 스캐폴드다. Figma가 **24시간 그래프 1개만** 확정해줬고, `주간` · `주간 온습도 분포` · `행동 분석`은 **제목만 있고 미설계**다.
→ 24시간 그래프는 지금 구현 착수 가능. 나머지 3개는 여전히 스펙 부족이며, 피드백에도 "7일, 30일은 어떻게 봐야할지 감이 안 옴"이라 적혀 있어 **디자이너 결정 대기**다.

### F. 색상 토큰 불일치

| 지표 | PRD §3.4 | Figma | 현재 코드 |
|---|---|---|---|
| 온도 | 주황 | `#ff3752` (적색) | `Theme` 기반 |
| 습도 | 파랑 | `#8abcfc` (연하늘) | 〃 |

Figma에 발행 스타일이 없어 hex를 직접 옮겨야 한다. `AppTheme`에 토큰으로 추가할지, 차트 전용 상수로 둘지 결정 필요 (프로젝트 규칙상 **하드코딩 색상 금지**이므로 토큰화가 맞다).
