## 1. 위험도 높음 — 이번 빌드에서 조회가 바뀐 곳

### A. 팬 타이머 (0.171.3 — 조회 컬럼에 `source` 추가)

**왜 보나:** 타이머 조회가 실패하면 에러 화면 없이 조용히 빈 목록이 된다. 그러면 카운트다운과 "타이머 끝" 알림이 사라진다.

| # | 절차 | 기대 결과 | 상태 |
|---|---|---|---|
| A1 | 홈 → 환기팬 타일 → [즉시 작동] → 작동 시간 **10분** → 전원 스위치 켬 | 스위치가 shimmer 뒤 켜짐. 시트를 닫으면 홈 타일 부제가 "켜짐 · 9m xxs 뒤 꺼짐"이고 초가 줄어든다 | ⬜ |
| A2 | A1 상태에서 앱을 **완전히 종료**(최근 앱에서 밀기) → 다시 실행 | 카운트다운이 이어져 보인다(시작부터 다시 세지 않음) | ⬜ |
| A3 | 환기팬 시트를 다시 연다 | 작동 시간 칩 "10분"이 선택돼 있다 | ⬜ |
| A4 | 전원 스위치 끔 | 타일 "꺼짐", 카운트다운 사라짐. 원래 끝날 시각이 지나도 "팬 타이머가 끝났어요" 알림이 **오지 않는다** | ⬜ |
| A5 | 다시 10분으로 켜고 **그대로 둔다**(약 10분) | 끝나는 시각에 팬이 꺼지고 "팬 타이머가 끝났어요" 알림 1회. 타일 "꺼짐" | ⬜ |
| A6 | 냉각팬 타일 → 30분 뒤 → 전원 켬 → 카운트다운 확인 → 끔 | 환기팬과 같게 동작한다(냉각팬은 30분·1시간·2시간만 있음) | ⬜ |

### B. 사육장 제어 기록 (0.173.0 — 조회를 전체 컬럼 `select()`로 바꿈)

**왜 보나:** 이 조회가 실패하면 온습도 상세의 제어 기록과 그래프 위 마커가 함께 빈다.

| # | 절차 | 기대 결과 | 상태 |
|---|---|---|---|
| B1 | A를 끝낸 뒤 홈 온습도 카드 → 온습도 상세 [일간] 오늘 → 아래 "사육장 제어 기록" | A에서 한 "환기팬 켜짐 / 꺼짐", "냉각팬 켜짐 / 꺼짐" 줄이 시각과 함께 보인다. 꺼짐 줄에 "-x℃ +y%" 같은 변화 또는 "작동 시점 온습도"가 있다 | ⬜ |
| B2 | 같은 화면 그래프 위쪽 마커 줄 | 기록 줄 수만큼 기기 아이콘 마커가 시각 위치에 있다 | ⬜ |
| B3 | 날짜 ‹ 로 어제 → 다시 오늘 | 어제 기록(있으면)이 보이고, 오늘로 돌아와도 목록이 비지 않는다 | ⬜ |
| B4 | 분무 타일 → 분사 시간 **3초** → [1회 분사 시작] → 2초 실행 취소 창이 지나도록 둔다 → 온습도 상세 다시 열기 | 기록에 "분무 3초 작동" **1줄**. 제목에 "자동"이 붙지 않는다(사용자 명령) | ⬜ |
| B5 | 분무 **9초** 1회 → 기록 확인 | "분무 9초 작동" 1줄(여러 줄로 쪼개지지 않음) | ⬜ |
