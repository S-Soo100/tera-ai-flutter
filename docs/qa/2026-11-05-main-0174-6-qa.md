# main 0.174.6(485) — 화면·기능 QA 스크립트

> 작성 2026-11-05. 대상은 지난 배포 APK 0.174.2 이후 main에 들어간 두 변경이다. 다른 배포를 하기 전에 확인한다.
> - **0.174.3:** 홈 팬 타일 부제 잘림 수정, 냉각팬 타이머 안내 문구 통일
> - **0.174.4~0.174.6:** 온도 보정을 사용자 보정값 하나로 정리. 새 서버 계약용 경로는 스위치 `FeatureFlags.tempOffsetUserContract = false`로 꺼져 있어서, **화면·동작·DB 값이 0.174.2와 완전히 같아야 정상**이다.
>
> 배경 문서: 계획 `docs/superpowers/plans/2026-11-05-temp-offset-user-contract.md`, 지난 QA `docs/qa/2026-11-05-apk-0174-android-qa.md`.

## 0. 준비

| 항목 | 값 |
|---|---|
| 빌드 | main `f85da79f` 이상, `pubspec.yaml` 0.174.6+485. 릴리스 모드(`flutter build apk --release`, 서명 키 `android/key.properties`는 메인 폴더에 있음) |
| 폰 | 지난번과 같은 Android 실기기(Galaxy S21+, 약 384dp)가 있으면 우선. 없으면 에뮬레이터를 쓰고 결과에 적는다 |
| 사육장 | 테스트 계정 사육장, **보정값을 보고하는 신 펌웨어 기기 1대**(온습도 설정에서 "온도 보정" 토글이 잠기지 않는 기기) + 가능하면 구 펌웨어 1대. **고객 기기 금지** |
| 시작 전 기록 | 테스트 기기의 현재 보정값(온습도 설정 화면 값 + DB `devices.temp_offset_c`). **끝나면 이 값으로 되돌린다** |
| 기록 | 항목마다 캡처, 시각(HH:MM:SS). 보정 저장 항목은 DB `commands`(action `set_temp_offset`)의 `payload`·`status`·`result`와 `devices.temp_offset_c`를 같이 적는다 |

상태: ⬜ 미실시 / ✅ 통과 / ❌ 실패 / ⏸ 보류

## B. 온도 보정 (0.174.6 — 화면·DB 값이 예전과 같아야 함)

| # | 절차 | 기대 결과 | 상태 |
|---|---|---|---|
| B1 | 온습도 상세 ⚙ → 온습도 설정(신 펌웨어 사육장) | "온도 보정" 토글 상태가 시작 전 기록과 같다. 켜져 있으면 "보정 값 ±x℃"가 기록값과 같다 | ⬜ |
| B2 | 구 펌웨어 사육장(있으면) | 토글이 잠기고 "펌웨어 업데이트 후 사용할 수 있어요"류 안내 | ⬜ |
| B3 | 보정 꺼진 상태에서 토글 켬 → 보정값 설정 화면 | "현재 측정 온도"가 홈 온도와 같고, "보정 온도" = 측정 − 0.1(기본 "빼기 0.1"). **[취소]** → 온습도 설정 토글이 다시 꺼짐. DB에 새 `set_temp_offset` 명령이 **없다** | ⬜ |
| B4 | 토글 켬 → 빼기 **1.0** → [저장] | "기기에 적용하는 중…" 뒤 15초 안 저장되고 화면이 닫힌다. 온습도 설정 "보정 값 -1℃". DB: 명령 `payload = {"offset_c": -2.5}`, `acked`·`ok`, `devices.temp_offset_c = -2.5` | ⬜ |
| B5 | B4 뒤 홈 온도 | 저장 전보다 약 1℃ 낮게 보인다(기기가 보정한 값) | ⬜ |
| B6 | 보정값 설정 다시 → 더하기 **0.5** → 저장 | DB `{"offset_c": -1.0}`, `temp_offset_c = -1.0`, 화면 "+0.5℃" | ⬜ |
| B7 | 온습도 설정에서 토글 끔 | 확인 모달 없이 바로 꺼짐 처리. DB `{"offset_c": -1.5}`, `temp_offset_c = -1.5`, 토글 꺼짐 | ⬜ |
| B8 | B4~B7 중 아무 때나 화면을 1분 이상 그대로 둔다 | 보정 화면·온습도 설정이 깜빡이거나 다시 그려지지 않는다(기기 행은 3초마다 갱신됨) | ⬜ |
| B9 | 오프라인 사육장(있으면) | 보정 토글·저장이 막힌다(예전과 같음) | ⬜ |
| B10 | 글자 크게(1.3배 이상) → 온습도 설정·보정값 설정 | 잘림·겹침 없음 | ⬜ |
| B11 | **되돌리기** — 시작 전 보정값으로 다시 저장 | 화면·DB가 시작 전 기록과 같다 | ⬜ |

**B에서 `payload`에 `user_offset_c` 키가 보이면 즉시 실패다** — 새 계약 스위치가 켜진 빌드라는 뜻이다(서버 배포 전이라 400).
