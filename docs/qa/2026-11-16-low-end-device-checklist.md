# 구형 폰 점검 목록 — 최소 지원 폰 기준 확정용 (2026-11-16)

판매할 때 "어떤 폰부터 된다"고 안내하기 전에, 최소 기준 후보 폰에서 핵심 기능이 되는지 확인하는 목록이다.

## 현재 상태

- **설치 가능 하한(빌드 설정):** Android 7.0(API 24, Flutter 기본 `minSdk`) / iOS 14.0(`ios/Podfile`, Xcode 설정)
- **스토어 요구:** Android `targetSdk` 36(Flutter 3.38.9 기본값)으로 Play 기준 충족. iOS는 최신 Xcode 빌드 여부만 본다(11월 TestFlight 업로드 통과).
- **실기기 확인된 폰:** 갤럭시 S21+(SM-G996N), 갤럭시 S24(SM-S921N), iPhone 16 Pro. 구형·저가폰 확인 기록은 없다.

## 최소 폰 기준 (제안 — 이 점검을 통과해야 확정)

| 구분 | 최소 모델 | 출시 | 메모리 | 고른 이유 |
|---|---|---|---|---|
| 삼성 플래그십 | 갤럭시 S10 / 노트10 | 2019 | 8GB | Android 12까지 업데이트됨(블루투스 "근처 기기" 권한) |
| 삼성 보급형 | 갤럭시 A51 | 2020 | 4~6GB | Android 13까지 업데이트되는 오래된 보급형, 저가 하한 확인용 |
| 아이폰 | iPhone XS · XR | 2018 | 3~4GB | iOS 17 지원 가장 오래된 기기 |
| 아이폰 저가 | iPhone SE 2세대 | 2020 | 3GB | 중고 저가 수요 |

판매 문구 초안: **"Android 12 이상 삼성 갤럭시(S10·A51 이후) / iOS 17 이상 iPhone(XS·XR·SE 2세대 이후), 블루투스 필요, 2.4GHz Wi-Fi 필요"**
(2.4GHz 전용 여부는 모델별 펌웨어 확인 필요)

제외: 갤럭시 A21s·A12 등 메모리 3GB 저가폰, iPhone 8·X(iOS 16까지).

**시간이 없으면 갤럭시 A51 + iPhone XR 두 대만** 본다. 둘이 통과하면 기준 확정.

## 점검 목록

릴리스 빌드로 진행한다(Android = 고객 배포 APK, iOS = TestFlight).
기기마다 모델명·OS 버전·앱 버전을 맨 위에 적는다.

### 1. 설치·로그인
- [ ] 설치 후 첫 실행 3초 안에 홈 표시
- [ ] 로그인 후 앱을 껐다 켜도 로그인 유지

### 2. 기기 등록 (블루투스) — 구형 폰에서 잘 막히는 부분
- [ ] 사육장 추가: 권한 요청 → 기기 찾기 → Wi-Fi 입력 → 등록 완료까지 한 번에
- [ ] 카메라 추가도 같은 흐름으로 완료
- [ ] Android 11 이하라면 위치 권한·위치 켜기 안내가 제대로 뜸
- [ ] 기기 상세 [Wi-Fi 바꾸기] 동작

### 3. 라이브 (가장 무거움)
- [ ] 첫 영상 10초 안에 표시
- [ ] 10분 연속 시청 시 끊김·멈춤 없음, 손에 쥐기 힘든 발열 없음
- [ ] 가로 전체화면 전환 부드러움
- [ ] 홈 버튼으로 나갔다 돌아오면 다시 연결
- [ ] 카메라 여러 대 좌우 넘김 시 버벅임 없음

### 4. 라이브 녹화 (구형 삼성 위험도 1순위 — 소프트웨어 인코더 사용)
- [ ] 2분 꽉 채워 녹화 시 영상 끊김·앱 종료 없음
- [ ] 녹화 중에도 라이브 화면이 멈추지 않음
- [ ] 업로드 완료 후 저장·공유 동작, 2분 파일 약 15MB 이하

### 5. 영상·화면
- [ ] 카메라 탭 영상 목록 빠른 스크롤 시 끊김 없음
- [ ] 하이라이트 재생목록 다음 영상으로 계속 넘겨 재생
- [ ] 온습도 상세 차트 좌우 스크롤 부드러움
- [ ] 커뮤니티 피드 자동 재생 + 스크롤 동시 진행 시 끊김 없음

### 6. 제어
- [ ] 분무·환기팬·조명 누르면 바로 반응(반영 보통 3초 안)

### 7. 오래 쓰기
- [ ] 30분 이것저것 사용해도 앱 저절로 종료 없음
- [ ] 30분 라이브 시청 배터리 소모량 기록(참고용)
- [ ] 휴대폰 글자 크기 최대에서 화면 깨짐 없음

## 판정 기준

- **2·3·4번 중 하나라도 실패** → 그 폰은 최소 기준에서 제외
- **5~7번이 조금 느린 정도** → "동작하나 권장 사양 미만"으로 기록
