## 라이브 연결 안정성 (2026-09-22 ~)

**라이브 연결 안정성**(2026-09-22, `webrtc_live_controller.dart`): 연결 1회=**세대**(`_gen`). 재연결·백그라운드·dispose마다 세대를 올리고 이전 세대의 콜백·ICE 폴링·타이머·offer 응답은 무시(이전엔 공유 `_active`라 이전 세션 후보가 새 피어에 섞였다). LIVE(`streaming`)는 **첫 프레임**(콜백 또는 `getStats` framesDecoded) 이후 — ICE connected는 `waitingVideo`. 첫 프레임 30초 무소식·재생 중 15초 정지=재연결. 백그라운드(paused)=연결 내림, resumed=즉시 재연결, 네트워크 종류 변경(`webrtcNetworkSignalProvider`)=즉시 재연결, 카메라 `is_online=false`면 자동 재연결 정지→온라인 시 재개. 피어·렌더러는 `webrtcPeerConnectionFactoryProvider`/`webrtcRendererFactoryProvider`로 테스트 교체(`test/features/my_cage/webrtc_live_controller_test.dart`). 서버 요청(연결 로그 테이블·TURN) `docs/handoffs/2026-09-22-camera-live-stability-server-requests.md`. **연결 결과 기록**(2026-09-23, 0.130.0): 세대마다 결과 1행(`streaming`/`failed`/`unresponsive`/`no_video`/`cancelled`) + 재생 종료 1행(`stalled`/`failed`/`closed`, `streamed_sec`)을 `webrtc_connect_logs`에 Supabase 직결 INSERT(`WebRtcConnectLogRepository`, 테스트 심 `webrtcConnectLogSinkProvider`). **`.select()` 금지**(SELECT 정책 없음 → RETURNING이 RLS 위반). `offer_attempts`·`answer_ms`는 offer 응답에서 받는다(>1=펌웨어 무응답). TURN은 별도 인스턴스로 결정(2026-09-23), 서버 배포 대기. **시청 세션 기록**(2026-09-25, 0.135.0): 라이브 화면 1회(시작·복귀→이탈·백그라운드)마다 `webrtc_view_logs`에 요약 1행(`LiveViewSession` — 첫 영상 ms·상태별 시간·수동 재시도·재연결 사유), 연결 행엔 `view_id`·`firmware_ver`. 조회는 운영자 전용 `ops.live_views`/`live_daily`/`live_timeline`(PostgREST 비노출 스키마 — public에 view를 두지 말 것, RLS 우회 누출). 기획 `docs/superpowers/specs/2026-09-25-live-view-session-logging-design.md`. **펌웨어 수정 전 앱 개선**(2026-09-24, 0.133.x): phase에 `stalled`(재생 중 5초 무진행, 영상 유지)·`recovering`(집중 복구 90초 안 자동 재시도, 버튼 없음) 추가, `failed`는 예산 소진·카메라 오프라인·망 없음·인증 실패만(버튼 + 60초 저빈도). 재시작은 정리 중이면 병합(`restart-merged`), 망·복귀·수동만 force. 망 신호 1초 디바운스·되돌아옴 무시·영상 중이면 3틱 유예. 개별 시도 예산 60초(ICE 단계 무한 대기 차단), 401/403은 재시도 없음. 재생 감시 1초 틱(정지 5틱 안내·15틱 재연결·통계 10틱 부재=`statsUnknown`만). **백오프 초기화는 영상 30초 안정(`stable`)과 수동 재시도에서만.** 제어기는 `ModuleLink` 3값(unknown이면 "확인 중", 제어는 계속 차단). 로컬 진단 버퍼 600건(`webrtcDiagBufferProvider`, 계정 전환 시 비움) → 마이페이지 "라이브 연결 진단 내보내기". 기획 §11·결과 `docs/design-audits/2026-09-24-camera-live-pre-firmware/RESULTS.md`. **2026-09-25 사용자 흐름 점검 반영(0.137.0):** 첫 영상 한도 30→10초(운영 connected→첫 프레임 p99 4.7초, 18초 키프레임 갭 해소), DB `is_online=false`면 offer 생략하고 바로 오프라인 안내(수동 재시도·망 복귀는 `_forceAttempt`로 한 번 강제), 실패 원인별 문구+할 일(`hintKeyFor` — no_video·stalled·ice·unresponsive·offline+마지막 신호), 저빈도 재시도는 실패 화면 유지(`quietRetry`). **화면에 안 보이면(TickerMode — 다른 탭·불투명 화면) 시청 기록은 즉시 닫고 30초 뒤 연결 해제**(`setViewerVisible`/`_pauseReasons` background·hidden), provider는 마지막 구독 해제 뒤 30초 linger(`kWebRtcHiddenGrace`) — 짧은 이동·카메라 넘김은 재연결 없음. 카메라 탭 스와이프는 `ScrollEndNotification`에서 확정(onPageChanged는 절반 지점에서 불린다), 드롭다운도 `syncHomeSetToCamera`.
