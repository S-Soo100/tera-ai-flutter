# Figma 대조 검수 규칙

사용자 지시 원문(2026-09-16): `docs/contracts/ui-common.md`.

- 화면을 Figma에 맞출 때는 같은 논리 화면 크기·SafeArea에서 다음을 **수치로** 확인한다: 간격·패딩, 폰트 크기·굵기·줄높이·자간, 실제 ColorSystem 색, 아이콘 프레임과 내부 그림 크기·정렬, 버튼 위치·활성 조건·터치 영역.
- "비슷해 보인다"로 통과시키지 않는다. 원본·앱 측정값과 수정 전후 캡처, 남은 차이를 기록하고 차이가 남으면 보고 후 확정한다. 원본을 확인하지 못한 항목은 검수 완료로 치지 않는다.
- 하단 버튼은 스크롤 내부 / 별도 영역 고정 / 콘텐츠 위 플로팅을 구분한다. 활성 조건, 좌우·하단 위치, SafeArea, 마지막 항목 접근성까지 확인한다. 모든 화면을 같은 footer 구조로 일괄 치환하지 않는다.
- **공통 하단 CTA**: 저장·선택 같은 주요 하단 버튼은 콘텐츠 위에 떠 있는 구조를 먼저 확인한다. "폼 끝에 있으니 스크롤 내부"라고 추정하지 않는다. 키보드 위치와 가려지는 마지막 입력칸 접근성을 함께 검증한다.
- 확정 사례: 그룹 구성원 선택의 선택 버튼(콘텐츠 위 고정, 목록이 뒤로 스크롤), 개체 정보 입력의 저장 버튼(정상·오류 상태 모두 플로팅).
